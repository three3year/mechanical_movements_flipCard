421. 用於船舶的筒狀引擎（Trunk engine）。活塞上連接著一根筒管（trunk），其下端直接與連桿（pitman）相連。筒管穿過圓筒端蓋上的填料函（stuffing-box）運作。活塞上側的有效面積因筒管而大幅減少。為了使活塞兩側的動力均等，高壓蒸汽會先作用於活塞上側，之後再排入下方圓筒的部分，並以膨脹方式加以利用。

422. 擺動式活塞引擎（Oscillating piston engine）。圓筒 A 的剖面呈扇形。活塞 B 連接於搖臂軸 C 上，蒸汽透過一個滑閥 D 交替地被引入圓筒，作用於活塞的一側與另一側，其方式基本上與一般的往復式引擎相同。搖臂軸連接於曲柄上以產生旋轉運動。

423. Root 的專利雙象限引擎（double-quadrant engine）。此引擎採用與第 422 種相同的原理；但使用了兩個單動式活塞 B、B，兩者皆連接於同一個曲柄 D 上。蒸汽透過一個進氣閥 a 交替地被引入，作用於兩個活塞的外側，並透過兩活塞之間的空間排出。活塞與曲柄的連接方式，使得蒸汽在曲柄旋轉的約三分之二期間作用於每個活塞，因此不存在死點。

424. Root 的雙往復式或稱方形活塞引擎。此引擎的「圓筒」A 為長方形，內含兩個活塞 B 和 C，前者於其中水平作動，後者則於前者內部垂直作動；活塞 C 連接於主軸 b 上曲柄的手腕 a。蒸汽引入口以黑色表示。兩個活塞會使曲柄旋轉，且沒有死點。

425. 眾多旋轉式引擎（rotary engine）形式中的一種。A 為圓筒，軸 B 從其中心穿過。活塞 C 單純就是一個固定於軸上的偏心輪，並於一點與圓筒接觸作動。蒸汽的引入與排出如箭頭所示，蒸汽作用於活塞一側的壓力，產生活塞與軸的旋轉。位於進氣口與排氣口之間的滑動擋板 D，會移出活塞的行經路線，讓活塞得以通過。

426. 另一種形式的旋轉式引擎，圓筒內有兩個靜止的擋板 D、D，而兩個活塞 A、A 為了能通過這些擋板，被設計為可在主軸 B 的輪轂 C 上的溝槽內徑向滑動。蒸汽同時作用於兩個活塞，產生輪轂與軸的旋轉。蒸汽的引入與排出以箭頭表示。

427. 另一種旋轉式引擎，其軸 B 於與圓筒偏心的固定軸承內作動。活塞 A、A 被配置為可在與軸同心的輪轂 C 的溝槽中滑進滑出，但它們始終與圓筒保持徑向，藉由嵌合於圓筒端蓋輪轂上的環（以虛線表示）維持此狀態。活塞穿過位於輪轂 C 中的滾動填料 a、a 滑動。

428. 印度橡膠旋轉式引擎（india-rubber rotary engine），其圓筒具有一層由印度橡膠製成的撓性內襯 E，並以滾子 A、A 取代活塞，這些滾子連接於從主軸 B 放射延伸的搖臂上。在印度橡膠與周圍剛性的圓筒部分之間作用的蒸汽，會將印度橡膠壓向滾子，使滾子繞圓筒旋轉並帶動軸轉動。

429. Holly 的專利雙橢圓旋轉式引擎（double-elliptical rotary engine）。兩個以齒輪相互嚙合的橢圓活塞，由進入其間的蒸汽所驅動，其方式使兩者朝相反方向產生旋轉運動。

以上這些旋轉式引擎皆可改裝為泵使用。
