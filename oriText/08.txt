69. B——具有單一齒的小輪——為驅動端，而輪 A 上齒與齒之間的圓周部分，則在小輪的齒未作動的期間，起到鎖定或擋止的作用。

70. 驅動輪 C 具有一圈輪緣（rim，以虛線示意），該輪緣外側在撥爪 B 未與凸柱接觸的期間，作為另一個輪 A 上凸柱的軸承與擋止之用。此輪緣上有一個開口，用來讓一根凸柱通過進入、另一根凸柱通過離開。撥爪的位置正對此開口的中央。

71. 驅動輪 B 的內側圓周（以虛線示意）作為鎖定機構，輪 C 上的凸柱中會有兩根靠在其上，直到撥爪 A 撞擊到其中一根凸柱時，其下方的下一根凸柱便會從護輪緣（guard-rim）的下方凹槽通過離開，同時另一根凸柱則從上方的凹槽進入輪緣中。

72. 為一種傾動式錘子運動（tilt-hammer motion），凸輪或稱推板輪（wiper-wheel）B 每旋轉一圈會將錘子 A 抬起四次。

73. 驅動輪 D 上固定著一根彎曲的彈簧 B；另一根彈簧 C 則連接於固定的支撐座上。當輪 D 旋轉時，彈簧 B 會通過強力彈簧 C 的下方，將 C 壓入棘輪 A 的其中一齒中，於是使 A 旋轉。制動彈簧（catch-spring）B 從強力彈簧 C 中脫離釋放後，會讓輪 A 保持靜止，直到 D 再旋轉一圈為止。彈簧 C 起到擋止的作用。

74. 藉由缺齒式斜齒輪（mutilated bevel-gear）C，將方向相反的均勻間歇旋轉運動賦予斜齒輪 A 和 B。

75. 桿 C 的往復直線運動，透過振動桿 D 末端的棘爪 B，將間歇的旋轉運動傳遞給輪 A。

76. 為另一種用於登錄或計算轉數的裝置。撥爪 B 支承於固定樞軸 C 上，該撥爪在大輪（僅部分繪出）每一次旋轉時，皆會被固定於該輪上的凸柱 D 撞擊一次。這會使撥爪靠近棘輪 A 的那一端被抬起，並使該輪轉動一齒的距離。當凸柱 D 通過之後，撥爪憑其自身重量回到原本位置，該端為鉸接式（jointed）以便能夠越過棘輪的齒。
