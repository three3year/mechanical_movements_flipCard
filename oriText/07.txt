60. 藉由皮帶傳遞兩種速度。下方軸上有四個皮帶輪，最外側的兩個為鬆動式（loose），內側的兩個為固定式（fast）。左側的皮帶被繪於其鬆動皮帶輪上，右側的皮帶則位於其固定皮帶輪上；因此會有較慢的運動被傳遞至下方軸。當右側的皮帶被移到其鬆動皮帶輪上、左側的皮帶被移到其固定皮帶輪上時，就會傳遞較快的運動。

61. 用於傳遞兩種速度的差動運動機構（differential motion）。皮帶被繪於下方軸上的鬆動皮帶輪上。中間的皮帶輪則牢固於該軸上，並在其輪轂處固定著一個小型斜齒輪。右側的皮帶輪如同左側者一般為軸上的鬆動式，並且橫向地帶動另一個斜齒輪。第三個斜齒輪在軸上為鬆動式，透過一條末端加重的摩擦帶（friction-band）加以固定。當推動中間皮帶輪時，會產生單純的運動；但當推動右側皮帶輪時，會將雙倍的速度傳遞給軸。第三個斜齒輪上的摩擦帶或稱制動器（curb），是為了在速度突然變化時允許它稍微打滑之用。

62. 用於傳遞兩種速度，其中一種為差動的變速運動。此機構與第 61 種非常類似，差別在於第三個斜齒輪連接於第四個皮帶輪上，位於其他三個皮帶輪的右側，並由上方軸上一個小型皮帶輪透過皮帶帶動。當左側皮帶位於承載中間斜齒輪的皮帶輪上，且右側的皮帶輪與軸朝同方向轉動時，第三個斜齒輪的旋轉量必須從「該軸原本會有的雙倍速度」中扣除。反之，若右側的皮帶被交叉，使其上的皮帶輪朝相反方向旋轉，則那個旋轉量必須加上。

63. 跳躍式或稱間歇式的旋轉運動，用於計量器（meters）和轉數計數器（revolution-counters）。左側由彈簧承載的落板（drop）以及附帶的棘爪（pawl），會被右側圓盤上的插銷抬起。插銷首先從棘爪處脫離，棘爪隨即落入星形輪的下一格空間。當插銷從落板處脫離時，彈簧會突然將落板向下拋，落板撞擊到棘爪的那根柱子，其動作作用於星形輪上，使其快速地旋轉一部分角度。每當有插銷通過時，此動作便重複一次。

64. 另一種跳躍運動的配置方式。運動由底部的蝸桿或無端螺桿（endless screw）——固定於驅動軸上——傳遞給蝸輪 B。在承載蝸輪的軸上，還套著另一根空心軸 A，A 上固定著凸輪（cam）。這根空心軸有一小段被切除。固定於蝸輪軸上的一根銷（pin），會頂住空心軸與凸輪，而按壓於凸輪上的彈簧則會將空心軸推回頂住該銷，直到到達比圖中所示位置稍遠處，此時，由於凸輪的特殊形狀，壓力的方向會發生改變，凸輪便會突然掉落——獨立於蝸輪的運動之外——並保持靜止，直到銷再次趕上它，屆時同樣的動作又會再次發生。

65. 左側的圓盤或稱輪 C，是驅動輪，其上固定著撥爪（tappet）A。另一個圓盤或稱輪 D，其表面凸出著一連串等距的凸柱（studs）。撥爪每旋轉一圈作用於輪 D 上的其中一個凸柱時，會使該輪 D 移動一個凸柱的距離。為了避免超過此距離，在一個固定的中心上安裝了一個類似槓桿的擋止裝置（lever-like stop）。此擋止裝置作用於輪 C 上所切出的一個凹槽（notch）中，而在撥爪 A 撞擊凸柱的那一瞬間，該凸柱亦面向槓桿。當輪 D 旋轉時，凸柱之間的末端會被推出，而另一端則進入該凹槽中；但當撥爪離開凸柱後，槓桿又會立刻被推回至下一個凸柱前方，並被 C 的圓周部分頂住其另一端而保持定位。

66. 為第 64 種的變形；一個重物 D 連接於固定在蝸輪軸上的搖臂上，取代原本的彈簧與凸輪來使用。

67. 為第 64 種的另一種變形；一個重物或稱擺錘（tumbler）E 固定於空心軸上，用來取代彈簧與凸輪，並與蝸輪軸中的銷 C 組合運作。

68. 驅動輪 B 上唯一的齒 A 作用於輪 C 的凹槽中，並使該輪 C 於每一次 C 完整旋轉時，都轉動一個凹槽的距離。此運動不需要擋止裝置，因為驅動輪 B 的圓周部分會嵌入輪 C 各凹槽之間的凹陷處，起到鎖定的作用。
