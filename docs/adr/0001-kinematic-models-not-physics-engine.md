# 模型採用運動學連動，而非物理碰撞引擎

最初的需求是「物理碰撞模型」，但模型改為以幾何關係（齒數比、皮帶傳動、連桿長度、繩索倍率）直接算出每個從動件的位置，由主動件驅動，不使用剛體物理引擎（如 Matter.js、Rapier、cannon-es）。原書的機構絕大多數是幾何約束運動；物理引擎模擬齒輪嚙合與皮帶時常打滑、卡住或抖動，反而無法準確呈現原文描述的轉向與比例。

## Consequences

- 模型沒有重量、慣性、摩擦或彈跳；滑輪組的「省力比」是由位移比換算後顯示，而不是模擬出來的力。
- 凸輪、棘爪、擒縱這類靠接觸運作的機構，日後要以運動學方式個別描述其接觸規則；若真的需要碰撞，應另立 ADR 局部引入，而不是把整體改成物理引擎。
