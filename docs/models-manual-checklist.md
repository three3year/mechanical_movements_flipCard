# 模型手動驗證清單

模型定義(`models/`)由 `npm test` 自動驗證;以下是自動測試不涵蓋的畫面行為。
部署到 GitHub Pages 後,在**桌機**與**手機**各跑一次,結果記在 `.scratch/interactive-models/issues/12-registry-completeness-and-manual-checklist.md` 的 Comments。

本機預覽要用靜態伺服器(例如 `python -m http.server`、VS Code Live Server),模型是 ES module,直接雙擊 `index.html` 無法載入。

## 切換

- [ ] 全書第 1–507 種,每張卡片的圖片區下方都有「插圖 / 模型」切換;剛開網頁時選在「插圖」
- [ ] 每章至少抽兩張卡片:切到模型、翻頁、點交互參照跳轉,都正常
- [ ] 切到「模型」後,線稿風 3D 模型自動慢速運轉;主動件是橘色
- [ ] 切回「插圖」後,和改版前完全一樣

## 模式記憶

- [ ] 模型模式下按「下一張 / 上一張」、鍵盤 ← →、切換章節頁籤,都停在模型模式
- [ ] 模型模式下一路翻頁(含跨章節),每張都直接顯示模型
- [ ] 翻到別張再回來,模型回到預設狀態(自動播放、初始視角、預設狀態按鈕)

## 手勢分流

- [ ] 模型模式下點擊 3D 畫面、按鈕、速度滑桿都不翻頁;點 3D 畫面以外的留白(左右兩側有淡箭頭、控制列空白處)依左右半邊翻頁
- [ ] 手機上在模型上左右滑動不翻頁、頁面不捲動
- [ ] 插圖模式下點擊左右半邊、手機左右滑動照常翻頁
- [ ] 游標移到主動件上變成手形;按住主動件拖動,整個機構跟著轉,自動播放立刻暫停,放開後維持暫停
- [ ] 在空白處拖動是轉視角;滾輪 / 雙指捏合縮放;「重設視角」回到初始角度
- [ ] 「播放 / 暫停」按鈕與速度滑桿有效;拖動速度滑桿時按方向鍵不會翻頁
- [ ] 滑輪組(第 12–22 種)拖繩端:往下拉重物上升,拉到底停住;自動播放時來回往復;角落讀數即時更新
- [ ] 會運動的線狀零件(皮帶、繩)有黑色間隔記號,記號之間每段一種實色(金黃 → 綠 → 紫輪流),記號與色段跟著材料移動、繞過輪子;封閉皮帶沒有色差接縫;繩固定端那段不動
- [ ] 第 6 種槓桿只在小角度內擺動,自動播放時來回擺
- [ ] 第 54 種:A 一直同向轉,輪轉將近一圈後停住、A 沿軸向穿過左側開口到齒條另一面,輪與 B 反轉;第 63、64、66、67 種:落板 / 凸輪 / 重物 / 擺錘到臨界點後看得到加速落下的過程(不是瞬移),落定後靜止等銷追上

## 狀態與標籤

- [ ] 第 2、5、7、8、9、10、23 種模型下方有狀態按鈕,標示目前狀態;切換時零件以短動畫移過去,播放 / 暫停不變
- [ ] 第 5 種有 B、第 7 種有 A B a b、第 23 種有 A B B C 字母標籤,轉視角時跟著零件走、永遠正對畫面
- [ ] 沒有字母的模型不出現標籤
- [ ] 每個會轉的零件有一處記號色(從動件藍、主動件深橘)與轉向箭頭,轉向一眼看得出;停住的零件(如第 7 種皮帶在中輪時的齒輪)不顯示箭頭
- [ ] 目標件是藍綠色(第 49 種上方的斜齒輪、第 54 種的 B、第 58 種下方的軸、第 63 種的星形輪、第 64/66/67 種的空心軸、第 69 種的 A、第 70/71 種的凸柱輪),主動件橘、其餘白,一眼看得出輸入與輸出
- [ ] 第 58 種:皮帶在哪個輪,那個輪與它那一對齒輪是實體,其餘皮帶輪與齒輪是淡灰半透明、沒有描邊;切換狀態時半透明跟著換

## 頁碼搜尋

- [ ] 頁籤下方「跳到圖號」輸入數字按 Enter 或「前往」:跳到該圖所在卡片、章節頁籤跟著換、返回鍵消失;輸入 40 跳到第 40–41 種並(模型模式下)選中圖 40
- [ ] 輸入框裡按 ← → 不翻頁;輸入不存在的圖號(如 0、999)不跳頁,輸入框短暫標紅或顯示瀏覽器提示

## 小頁籤與交互參照

- [ ] 第 16–17、19–22 種在模型模式下有「圖 N」小頁籤,一次只顯示一個模型,預設選第一張
- [ ] 模型模式下點說明文字裡的「第 N 種」,目標若有模型就顯示模型;跳到多插圖條目時選中被引用的那一張
- [ ] 按「返回」或 Esc 回到原卡片的模型(原本選的小頁籤)

- [ ] 切換插圖 / 模型、翻頁時不閃白;模型模式下翻頁時卡片高度不跳動(插圖與模型兩種模式本身高度不同,切換時卡片會整體換成另一種高度,但不會先塌陷再撐開)
