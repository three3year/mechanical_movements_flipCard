## 這一族的總結

- 18 張都查過四項。有修的 18 張,沒有問題的 0 張。
- **主動件換了零件**(規則 7,原文寫了輸入):第 158、159 種圓盤 → 踏板;第 167 種鼓輪 → 往復的桿;第 168、169 種第二曲柄 → 往復動力的搖桿(原圖右端往上的那一截)。這五張的主動量改成「轉動件的相位」,`driver.cycle` 的一程是半圈:讀者抓的是往復件,播放時轉動件等速轉,經過死點不會跳。
- **目標件換了零件**:第 158、159 種踏板 → 圓盤(票上要重判的第 158 種:踏板踩動的目的是讓圓盤轉;以前因為主動件取圓盤,目標件才改標在另一端的踏板);第 167 種桿 → 鼓輪;第 163 種撥叉 → 閘門軸(這組調速器的目的是控制閘門,補上遠端的齒輪傳動後閘門軸畫得出來)。第 156、157 種的目標件仍是往下的直桿,只是直桿拆成短連桿 + 在導套裡走直線的直桿,目標件標在直桿上。
- **第 35–85 種外觀受影響**:無。共用模組的改動:`verify/replay.js` 修了一個 bug(見下),`models/pitman-crank.js` 只有第 168、169 種用到。
- **`verify/replay.js` 的修正**:自由零件的碰撞形狀裡若有近乎零質量的細長凸包(擠出面三角化時的狹長三角形),整個零件在重演裡會凍住不動、也不受重力;現在略過這種凸包。第 166 種的連桿原本因此一動不動。全書受影響的模型另外列在待確認清單的複查進度裡。
- 「未修」豁免:原本 0 項,現在 0 項。「演出的接觸」豁免:第 155 種 2 項(棘爪以固定角度畫在槓桿上)移除,改成由接觸算。
