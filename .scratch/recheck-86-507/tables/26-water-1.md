- 「未修」豁免:原本 0 項,現在 0 項。「演出的接觸」豁免:原本 1 項(第 439 種),現在 0 項。
- 動力重演:新增並通過 2 張(第 439 種閥桿頂到墊塊把閥門頂開、第 441 種水桶被固定銷撥斜)。不適用的:由水流帶動的水車、渦輪(430–438、442、443,流體是示意,ADR-0002);第 440 種靠水的重量翻倒(重演裡沒有水);第 444 種水錘泵的閥由水的動量開關;第 445–446 種沒有會動的零件;第 447 種船由水流推舵;第 448、449 種的閥瓣由水頂開(流體傳動,`powered`)。
- 瞬移掃描(`node tools/scan-models.mjs 60 430 … 449`):沒有報出(第 448、449 種的閥瓣原本在換向的瞬間直接翻開 / 闔上,已改)。
- 檢查點:`tests/water.test.js` 全過(第 439、441、448 種的斷言改寫:閥門由閥桿頂到墊塊打開、水桶加速落下;水桶被固定銷撥斜、加速擺回;閥瓣加速落回);`npm run verify -- 430-449` 通過;插圖並排截圖每張四個相位。
