# 複查逐圖表格:擒縱機構 三(第 306–314 種)

票:[17-escapement-3](../issues/17-escapement-3.md)。規則見[規格](../spec.md)的「回饋規則」;用語見 `CONTEXT.md`。

## 這一族的總結

- 9 張都查過四項,9 張都有修。原本的擒縱都是照擺的相位查表(演出的動作),現在全部改成由接觸算,沿用第 15 族的做法(見 [15-escapement-1](15-escapement-1.md) 的總結)。槓桿、止動器、制動爪、重力臂這類鉸接的零件用 `periodic` + `fall` 逐步算:被推就跟著動,沒被推時靠彈簧或重量加速落回、碰到擋銷就停。
- `models/escapement.js` 的 `periodic` 修了一處:不累積的量(槓桿、臂的角度與速度)以前每週期會把一點沒收斂的殘差接到下一週期,播得越久越漂(第 310 種的臂每週期往裡漂約 0.03°,最後壓進抬升銷);現在這些量每週期回到原值,殘差平均分攤到整個週期。用到它的第 291、296、308–314 種都複驗過。
- **第 313 種照原圖重做(維護者 2026-10-08 決定)**:不再左右鏡像,擒縱輪在左、直立的止動器在右(下端 D 固定在座上)、擺輪的滾子在右上。維護者看過實物的動畫(彈簧止動式:擺輪往一邊擺時解鎖石推通過彈簧、壓著止動器的角把止動器推開,往另一邊擺時只撥開通過彈簧),判定原圖的配置說得通;原文「向左」與「擋止 E、P」照插圖為準,寫進模型註解。共用模組 `models/detent-escapement.js` 改成機構(`detentMechanism`,接觸的算法)與各圖的幾何、外觀(`detentModel`)分開:第 313 種照原圖量出位置,在世界座標寫自己的幾何,鏡像與整組轉動的選項沒有圖用,移除。第 291 種的幾何與外觀搬到 `models/fig291.js`,數值不變——改動前後的模型定義與兩個週期裡取樣的 201 個姿勢逐位元相同,外觀不變。照原圖做時調了機構參數(沒有回到鏡像):鎖石做成上寬下窄的楔形,鎖面往右上斜 15°(止動器繞下方的 D 推開時,水平的鎖面會往上頂進齒),下半部往右縮(讓開被放開、沿著鎖石左面下滑的齒;代價是推開的頭一小段,齒沿著斜的鎖面前進約 0.007 齒才放開,實物解鎖時輪不前進);大滾子半徑 0.74、只伸進齒尖圓 0.03(鎖住時齒尖落在滾子掃過的範圍外),缺口 32°、方位照掃描結果取在可行範圍的中間。打開時停在衝量的那一刻(原圖畫的是齒 A 推叉瓦 P),重演改成明寫從主動量 0 開始。`models/escapement.js` 的 `periodic` 與 `wheelByContact` 各修一處(查表的寫法相同):主動量剛好落在週期邊界時,浮點誤差讓查表的索引變成 −1(第 313 種的新測試碰到);改成夾在 0 以上,其他圖的結果不變(`npm test` 與全書實體驗證通過)。
- **主動件換了零件**:無。**目標件換了零件**:無。
- **轉向改了**:無。
- **第 35–85 種外觀受影響**:無。
- 「未修」豁免:原本 9 項(第 306–314 種的重演),現在 0 項;新增「重演做不出來」4 項(第 310、311 種)。「待確認」豁免原本 14 項、「演出的接觸」4 項(第 308、310 種)、其他簡化畫法 3 項(第 308、311、314 種),全部移除。
- 動力重演:9 張都宣告了。7 張通過;**第 310、311 種(三腳式重力擒縱)寫成「重演做不出來」的豁免**:兩支重力臂與擒縱輪都是自由零件,擺推開一支臂放開輪之後,輪在重演裡從靜止加速轉過約 60° 才碰到另一支臂的擋止,以那個速度把很輕的臂撞開(臂的質量由外形算,重演的質量、力矩與摩擦是全書一致的預設值),輪一路轉走。第 309、312 種放開後只轉半個齒距,臂擋得住,通過。臂的擋銷原本畫在機架裡,而重演不算臂和機架之間的碰撞(臂的軸插在機架上),等於沒有擋銷;四張都把擋銷另做成一個零件。臂被抬起、擋住腳、落回的過程另由模型的測試檢查。
- 瞬移掃描:第 307 種的三腳輪原本一格轉 19°,把放開後的加速放慢後沒有報出;其餘沒有報出。
- 檢查點:`npm test` 全過;`npm run verify -- 288-321` 通過(這一族的豁免只有第 310、311 種的重演 4 項);`npm run verify` 全書通過;插圖並排截圖每張至少一個相位,第 314 種兩個相位。
