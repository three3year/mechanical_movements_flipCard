# 複查逐圖表格:擒縱機構 一(第 288–296 種)

票:[15-escapement-1](../issues/15-escapement-1.md)。規則見[規格](../spec.md)的「回饋規則」;用語見 `CONTEXT.md`(由接觸算、演出的動作、主動件、目標件、動力重演)。

## 這一族的總結

- 9 張都查過四項,9 張都有修。原本每一張的擒縱都是**演出的動作**:輪的進退照擺的相位查表(每擺一次放過半齒),叉瓦和齒的外形沒有真的相碰,所以有「未修」的重演豁免與「待確認」的干涉 / 憑空連動豁免。現在全部改成**由接觸算**,豁免全部移除。
- **擒縱的接觸做法(後面三族沿用)**:擒縱輪當成受固定力矩(重錘或發條)的零件,主動量每走一小步——擋它的零件(叉瓦、擋止、鎖石)壓進齒裡,輪被推開(回退或被推著走);沒被壓到時,輪從當下的速度以固定的角加速度轉,碰上就停(放開後不是瞬移,是加速落到下一個擋處)。從起點空走兩個週期,取之後一個週期當作穩定的週期;每週期的前進湊成整數個齒(誤差平均分攤)。共用的程式在 `models/escapement.js`:`escapeByContact`(一般的輪)、`crownByContact`(冠狀輪,在前後兩個切面上算)、`anchorPallet`(格拉漢式作圖:樞軸在兩個叉瓦處齒尖圓切線的交點,鎖面與樞軸同心或帶回退 / 拉力)、`periodic` + `fall`(槓桿、止動器、重力臂這類鉸接的零件,逐步算被推、加速落回)。新增 `models/supports.js` 的 `plateBar`(鐘錶夾板條),輪軸與擒縱叉的軸都往後伸進夾板條(原圖都沒畫,推斷)。
- **主動件換了零件**:無。**目標件換了零件**:無(重判過:擒縱的目的是讓輪系一齒一齒地放行,目標件仍是擒縱輪)。
- **轉向改了**:第 289 種照原圖箭頭改成逆時針、第 290 種照原圖箭頭改成順時針(原文都沒寫,以前的模型與箭頭相反)。
- **第 35–85 種外觀受影響**:無。`models/escapement.js` 原有的 `escapeStep` 等函式沒改(第 234、237、238、402 種仍在用,複驗通過);只新增函式。
- 「未修」豁免:原本 5 項(第 289、290、291、293、296 種的重演),現在 0 項。「待確認」的干涉 / 憑空連動豁免原本 9 項(第 289–296 種),全部移除。
- 動力重演:9 張都宣告並通過。擒縱輪是自由零件(受固定力矩),擺、擺輪照模型帶動;第 291、296 種另外把止動器、通過彈簧、槓桿也放成自由零件。
- 瞬移掃描(`node tools/scan-models.mjs 120 288 … 321`):只報出第 290 種的字母 E、H(一格移 0.17)——它們跟著齒走,輪放開後落一程時齒走得快,是刻意的;零件本身沒有報出。
- 檢查點:`npm test` 全過;`npm run verify -- 234 237 238 402 288-321` 通過(0 個未豁免的問題;這一族沒有豁免);共用模組改過,`npm run verify` 全書也通過;插圖並排截圖每張至少一個相位。
