# 12 — 複查:接頭與器具 一(第 243–258 種)

**What to build:** 把第 243–258 種(16 張)照[規格](../spec.md)複查一遍、修掉查到的問題,留下這一族的逐圖表格。做完後,讀者在這一族看到的模型都由接觸算、看得出轉向與相連、主動件與目標件標對、動作與原文一致;維護者打開表格就知道每張查了什麼、改了什麼。

第 247 種的「演出的接觸」豁免。第 251 種是腳本產生的重演宣告,要確認通過的理由。第 254–258 種是只有主動件在動而不標目標件的舊決定:重查,只寫建議。

**Blocked by:** 01 — 曲柄與凸輪(並定下逐圖表格格式)

**Status:** ready-for-agent

- [ ] 每張圖照規格的四項查過:回饋規則、原文對照(轉向、轉速比、動作順序)、動力重演、插圖外形對照(模型與插圖並排截圖,取幾個相位),查到的問題修掉
- [ ] 靠接觸或重力運作的模型都宣告了動力重演並通過;真的卡在重演引擎限制的,寫說得出具體原因的豁免(不以「未修:」開頭)
- [ ] 這一族沒有「未修」豁免;「演出的接觸」豁免改成由接觸算,或改寫成具體原因
- [ ] 拿不準的地方照「原文 > 實物可行 > 插圖外形」決定,寫進模型註解與待確認清單
- [ ] 維護者的舊決定有重查;要推翻的只寫建議,放在待確認清單最上方,模型不改
- [ ] 新斷言對應原文(轉向、比例、順序、每程推進量、接觸不穿入),放進該章的測試檔
- [ ] `npm test` 全過;`npm run verify` 在這一族的圖號上通過;動到共用模組時全書 `npm run verify` 也通過
- [ ] 這一族修完後,瞬移掃描在這些圖號上沒有報出(刻意的除外,寫進表格)
- [ ] 逐圖表格完成:每張圖一列,沒問題的也有一列;主動件換了零件、目標件換了零件、第 35–85 種外觀受共用模組影響的,都明確寫出
- [ ] 待確認清單與豁免清單更新,待確認清單照審核關卡的流程重新發布鏡像
- [ ] 這一族一個提交,訊息說明改了什麼
