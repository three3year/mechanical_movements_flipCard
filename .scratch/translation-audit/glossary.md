# 術語表:英文術語的統一譯法

2026-10-10 全書中譯檢查時定下。以後改 `oriText/` 或新增中譯,同一個英文術語照這張表譯;要改表裡的譯法,先改這張表、再全書一起改。各圖改了什麼見各族的改動表([README](README.md))。

「改了的圖號」是這次實際把舊譯換掉的圖;其餘出現處本來就是統一譯法。

## 統一譯法

| 英文 | 統一譯法 | 不再用的譯法 | 改了的圖號 | 理由 |
| --- | --- | --- | --- | --- |
| gear(當「機構、裝置」用:valve-gear、reversing-gear、hand-gear) | 閥動機構、換向機構、手動操縱機構 | 閥門齒輪機構、換向齒輪機構、手動齒輪機構 | 171、179、181–182、185、186 | 這裡的 gear 是整套機構,圖裡沒有齒輪 |
| gearing(分詞「與…嚙合」) | 照句意譯成「嚙合」 | 齒輪機構 | 499 | 第 499 種 gearing with a pinion 是動詞 |
| frictional gearing | 摩擦傳動機構 | 摩擦齒輪機構 | 413 | 摩擦輪沒有齒 |
| cog-wheel | 齒輪(mutilated cog-wheel:缺齒式齒輪) | 棘輪 | 121、216 | cog-wheel 是齒輪,不是 ratchet-wheel |
| mutilated | 缺齒式 | 缺齒 | 216 | 全書原本就用「缺齒式」 |
| bevel-gear、bevel-wheel、bevel gearing | 傘齒輪、傘齒輪傳動 | 斜齒輪 | 7、25、37、49、53、61、62、74、87、161、162、173、226、357、366、368、372、495、503 | 「斜齒輪」現代多指 helical gear;模型註解一律用傘齒輪 |
| miter-gears | 等徑傘齒輪 | 等徑斜齒輪 | 25 | 同上 |
| wrist(wrist-pin) | 腕銷 | 手腕 | 143、146、156、173、176–177、220、279、329、354、401、424 | 字面直譯「手腕」讀者看不懂 |
| crank-wrist、crank-pin | 曲柄銷 | 曲柄手腕 | 93、122、279、331、354 | 同上 |
| journal | 軸頸 | 軸承 | 331 | journal 是被支承的那段軸,bearing 才是軸承 |

| pulley(繞繩、索、鏈、線的) | 滑輪 | 皮帶輪 | 12–15、18、19–22、23、82、124、129、154、159、227、228、261、320、439、458、459、490、501 | 沒有皮帶;繞皮帶的才是皮帶輪 |

## 依語境分譯(同一個英文,不同中文都對)

| 英文 | 譯法 | 怎麼分 |
| --- | --- | --- |
| pulley | 皮帶輪 / 滑輪 | 繞皮帶(含 fast/loose pulley、cone pulley)譯皮帶輪;繞繩、索、鏈、線的譯滑輪。第 244 種測功計的制動輪不繞繩,保留皮帶輪 |
| cylinder | 汽缸 / 泵缸 / 液壓缸 / 圓筒 | 裝活塞的照上表;幾何的圓柱、滾筒、開溝槽的圓筒、圓筒式擒縱機構(cylinder escapement)、印刷機的滾筒保留「圓筒」;左輪的 cylinder 譯「轉輪」 |
| arm | 搖臂 / 臂 / 輻臂 | 繞支點來回擺的(含 rock-arm、vibrating arm)譯搖臂;隨軸整圈轉、固定不動、或零件的一段譯臂;輪的輻條譯輻臂 |
| vibrate | 擺動 / 振動 | 來回擺譯擺動;真的小幅快速震動(第 420 種鐘體)保留振動;oscillating column 是專名「振盪水柱」 |
| pitch | 螺距 / 齒距 | 螺桿譯螺距,齒輪譯齒距 |
| link | 連桿 / 鏈節 | 連桿機構的 link 譯連桿;鏈條的一節譯鏈節 |
| strap | 皮帶 / 偏心環 / 條板 / 帶 | 傳動用譯皮帶;偏心輪的環箍譯偏心環;第 244 種譯條板;制動帶譯帶 |
| shaft | 軸 / 豎井 | 礦坑的 shaft 譯豎井 |
| throw | 偏距 / 升程 / 行程 | 見上表 |
| stop | 擋止 / 擋止裝置 | 零件本身譯擋止,一整套譯擋止裝置 |

## 檢查過、保留的譯法

| 英文 | 譯法 | 為什麼保留 |
| --- | --- | --- |
| bell-crank | 曲柄搖臂 | 全書一致,意思沒錯;和 elbow-lever 並列時(第 153 種)後者譯肘形槓桿 |
| rag-wheel | 鋸齒輪 | 第 237 種 crown-ratchet 的別名,譯法可接受 |
| crown-wheel | 冠狀齒輪 / 冠狀輪 | 兩種都看得懂,這次沒有統一 |
| endless screw | 蝸桿 / 無端螺桿 | 兩種都在用,第 202 種並列「蝸桿或無端螺桿」 |
| pallet | 叉瓦 / 擒縱叉瓦 | 同一個零件,長短兩種寫法 |
| tappet、wiper、click、detent | 撥爪、推板、制動爪、止動裝置 | 全書一致 |
| gab | 鉤口 | 第 186 種網站註記:gab 是術語,不是 gap 的錯字 |
| wheel-work(第 412 種) | 齒輪機構 | 絞盤底部確實是齒輪 |

## 原文本身有錯時的寫法

- **網站有勘誤註記**(第 55、145、202、353、464 種):正文照勘誤改,第 202 種另加「(原書誤作第 30 種,依 507movements 更正)」。第 55 種(D 改 B)中譯原本就已正確。
- **網站沒有勘誤、但依上下文明顯是筆誤**(第 68、432、495、504 種):正文依上下文改正,後面加「(譯注:原文作…,依…應為…)」。
- **英文的字母或專名和中譯不同、無法判斷誰對**:照網站英文(第 477 種 Hoard & Wiggin)。
