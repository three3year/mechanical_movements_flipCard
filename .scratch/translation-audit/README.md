## 怎麼做的

1. 用 curl 把 507 頁抓下來離線比對(第 262、263 種是合併頁 `mm_262-263.html`)。英文取 `<div class="main">` 裡第一個 `<p>`,網站註記取「Notes:」之後的 `<p>`;依 `oriText` 的條目標頭把英文、註記和中譯配成對(487 條,涵蓋 1–507 每一張)。
2. 分 10 批交給子代理逐句比對(第 186–250 種上一輪已比對過,這次只收術語),每批輸出「舊片段 → 新片段」與術語用法。我逐筆看過,調整了幾筆後套用。
3. 彙整全書術語(788 個英文詞),定出統一譯法:能機械替換的直接換(傘齒輪、腕銷、肘形槓桿等),要看語境的(圓筒/汽缸、振動/擺動、搖臂/臂、皮帶輪/滑輪)再交給子代理逐處判斷,我看過後套用。
4. 套用時每筆都確認舊片段在該行恰好出現一次;改完 `python tools/gen_data.py`、`npm test`。

## 什麼算問題

- **誤譯**:意思和英文不同(零件認錯、方向或主被動弄反、字母或圖號錯、語氣改變意思)。
- **漏譯 / 增譯**:漏了子句、字母、限定語,或加了英文沒有、會誤導的內容。
- **網站勘誤**:網站註記說原書有錯,中譯還跟著原書。
- **原文疑誤**:網站沒有勘誤,但英文依上下文明顯是筆誤;正文依上下文改正,加「(譯注:原文作…)」。
- **用詞統一**:同一個英文術語在全書譯成同一個詞,見 [glossary.md](glossary.md)。

不改:語序、文氣、標點、可接受的意譯、同義換字。
