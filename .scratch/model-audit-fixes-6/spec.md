**來源:** 2026-10-26 第 1–85 種第一次照 `docs/agents/model-audit.md` 做八類檢查(複查),分 12 族,報告在 `.scratch/model-audit/00a-belts-1.md`–`00l-intermittent-4.md`,共 110 筆問題、19 題待決。同日維護者回覆「全改」:19 題全部照建議決定(各題已補「決定(2026-10-26)」行),110 筆全部修。第 70、71 種 2026-10-04 的「維持現狀」一併推翻(00j 第一題)。

## Problem Statement

第 1–85 種的實體驗證通過(85 張 0 個未豁免、39 項豁免),剛性與外形的檢查也是 0 張;但這一段以前一直是「維護者看過、不主動複查」的範圍,第一次照八類查下來,讀者與維護者會碰到下面幾類問題:

- **零件沒相連、沒裝上**(一半以上的問題):輪沒有軸、軸沒有軸承、機架懸空或分成不相連的幾塊、樞軸只是一塊板。
  - 機架與軸:第 7、34、49、53、55、57、63、65、68、69–72、75–79、81、82、85 種。
  - 撥桿碰不到它要推的東西:第 47、48、52、53 種的槓桿頂端沒伸進離合器的頸槽,推不動滑動半;第 47 種的摩擦盤接合時根本沒碰到。
  - 該是一件的分成兩件、或懸在半空:第 27 種的扇形凸塊、第 39 種飛輪與太陽齒輪、第 49 種棘輪嵌在傘齒輪轂裡、第 56 種主軸組、第 61、62 種行星傘齒輪的橫桿、第 81 種齒條的齒。
  - 繩頭懸空或綁在會轉的零件上:第 14、15、18 種。
- **照時序擺放、不是由接觸算**:棘爪、撥爪、擋止的動作是照主動量的時間表演出來的,實物上不會那樣動。
  - 第 49、78、79、82 種的棘爪從沒碰到齒,輪的轉角照臂的角度算。
  - 第 63、75、76、83、84 種的動力重演不成立(「未修:」豁免),這次查出了實體原因。
  - 第 65、70、71 種的擋止與撥爪:槓桿照正弦擺、撥爪穿過凸柱、凸柱嵌進輪緣。第 70、71 種的動力重演宣告被共用模組丟掉,從來沒跑過。
  - 第 64、66、67、68 種靠接觸或重力運作,卻沒有動力重演宣告。
- **原文沒演出或對不上**:
  - 第 3 種兩個導引輪沒有「並排」;第 9、10 種錐形皮帶輪的「逐漸加快或減慢」只有五個跳段;第 16、17、19 種的穿繩與省力比和插圖不同(第 19 種照原圖是 1:26,模型是 1:7)。
  - 第 30 種的矩形滾筒做成四瓣形;第 33 種的橢圓公式長短軸寫反,初始姿勢差 90°;第 46 種「補償發條放鬆時的力量損失」沒有讀數。
  - 第 53 種沒有原文說的鍵;第 56 種偏心溝的原理沒做出來;第 62 種少了鬆動輪與中間輪,「兩種速度」只演了一種。
  - 第 73 種彈簧 C 沒當擋止;第 77 種原文「幾乎連續」,每一程卻停將近一半;第 83 種原文的輸入是桿 A,模型的主動件是搖臂軸;第 84 種原文的調速器與節流閥沒畫。
- **豁免原因和這次量到的不合**(照維護者 2026-10-20 的決定,以這次的量測為準):
  - 第 26 種冠狀齒輪咬合處的齒距小 12%;第 29 種正齒輪相位差 0.035 弧度;第 31 種蝸桿中心距在程式裡故意縮短 0.04(第 104 種也一樣)。
  - 第 37 種齒栓和左輪的齒對不上;第 42 種兩輪法向齒距差 13%;第 54 種小齒輪換邊時沒經過開口、從齒栓中間穿過。
  - 第 65、75 種豁免寫的原因和量到的不同。
- **讀者讀不出**:
  - 轉向箭頭看不出方向或被擋住:第 2、25、29、36、40、41、43、44、45、72、74 種。
  - 第 46 種初始畫面和插圖不同;第 62 種看不出右皮帶是開口還是交叉;第 66、67 種取景只涵蓋蝸桿一圈,重物落下時出畫面。
- **實體驗證看不到的**:
  - 第 12–23 種的吊桿與吊帶插到輪心,和繞過輪的繩在同一平面相交(繩對桿不算干涉)。
  - 第 22 種拉到底時繩被夾在兩輪緣之間。
  - 第 81 種彈簧被壓到比簧圈並緊還短;同樣的錯在第 96、136 種。
  - 第 79 種兩支臂穿過輪轂環(實體驗證把空心圓柱當成軸)。
- **其他**:第 11 種從動輪正對皮帶筒、皮帶斜著進輪;第 23 種內圈判讀錯、切換狀態時導引輪不轉;第 50、51 種軸端與環的形狀和插圖不同;第 54 種軸承座的長槽沒畫;第 84 種切換狀態時框架被動畫拉回、置中時沒停在原處。

## Solution

照 12 份報告逐筆修,修法照各筆的「建議修法」與 19 題的決定。先做幾件跨圖的事,讓共用同一份程式或同一種錯的圖一次改好;再依族逐張修;最後全書收尾。

跨圖的事:

1. **滑車外殼**:滑輪畫成有外殼的滑車(兩側夾板夾著輪、軸穿過夾板),吊鉤、吊帶與繩頭都接在外殼上,繩從兩片夾板之間過。做成一份共用的畫法,第 12–23 種都改用它。
2. **離合器的撥叉**:共用的槓桿加一個叉頭,滑動件的轂上開出真的頸槽,叉夾在頸槽裡推溝壁;第 47、48、52、53 種一起用,第 56 種照同一種做法。
3. **棘爪由接觸算**:第 49、78、79、82 種的棘爪改成鉸接在臂上、和齒同一層,靠自重或彈簧(推斷)搭在齒上,推動由接觸算,沿用第 86 種以後已在用的棘爪共用模組;第 75、76、83 種照各自的建議改幾何。改完各張的「未修:」豁免拿掉。
4. **轉向箭頭看得出**:照各筆的建議調預設視角或箭頭位置;第 40、41、44 種在共用模組裡改視角,第 45 種同一個值。
5. **檢視器的位置接續**:切換狀態時,零件可以逐件宣告「位置也以偏移量接續」(現在只有轉角與皮帶相位接續)。給第 84 種的框架與桿 A 用,置中時框架停在原處。

逐張的修正見各族報告;修完每一筆在報告裡寫狀態行,pending.md 跟著更新,鏡像重新發布。

## Testing Decisions

- **接縫**:
  - 沿用現有的三個:模型定義(`npm test`,對各圖匯出的 pose() 與接觸函式下斷言)、實體驗證(`npm run verify` 與它自己的 `npm run test:verify`,動力重演的宣告也在這裡把關)、維護工具的測試(`npm test` 裡的工具測試)。
  - 只新增一個:檢視器切換狀態的接續邏輯抽成純函式模組,測試放進 `npm test`(前例是取景取樣的純函式模組與 `tests/framing.test.js`)。
- **好的斷言**:
  - 對到原文的一句(例:第 3 種「兩個導引輪並排安裝」= 兩輪同軸;第 19 種 1:26;第 77 種「幾乎連續」= 每程不動的比例 < 15%)。
  - 對到接觸:相碰的一對間隙接近 0、少轉一點就穿入、全程不穿入;鎖住期間把從動輪轉一點就會穿入(第 68、69 種)。
  - 對到守恆:繩長、鏈長、桿長不變;第 42 種兩輪法向齒距相等;第 46 種輸出力矩在放鬆過程中變化不大。
  - 對到實物限制:彈簧全程長於並緊長度(第 81、96、136 種);繩段不和吊桿、外殼相交(第 12–23 種)。
  - 不重複模型自己的公式、不只數零件的塊數。第 37、65 種只驗模型公式的斷言改掉。
- **先寫失敗的測試再改**(TDD):每一筆能用上面四種斷言表達的,先寫出現在會失敗的斷言,再改模型。第 33 種的初始姿勢、第 47 種摩擦面的間隙、第 48、52、53 種叉在頸槽裡、第 54 種換邊時穿過開口,都是例子。
- **動力重演**:修掉「未修:」的圖與第 64、66、67、68、70、71 種,重演的期望對到原文(例:「下一根插銷抬起落板時星形輪不動」)。
- **以工具報 0 為準、不逐張寫測試的**:一件掃描報出的機架與塊不相連(修好後該範圍 `node tools/one-piece.mjs` 不再報,或報出的每一項有寫在註解的實物理由)。
- **前例**:
  - 第 216 種換手由外形相碰決定、量交出與接手那一刻的間隙。
  - 第 206、236 種的棘爪由接觸算、兩程推進大致相等。
  - 第 198 種以兩根定長的桿鉸接(桿長不變)。
  - 第 371 種曼格輪換邊經過開口、軸在長槽裡。
  - 第 119 種主動件的 `period` 與取景的測試。
- **每張票的完成條件**:
  - 該範圍 `npm run verify -- 圖號…` 通過(沒有過時的豁免)、`npm test` 全過。
  - 該範圍一件、剛性、外形的檢查不再報出已修的問題。
  - 每張改過的圖截四個相位(含斜後方、放大接觸處)對照原圖。
  - 報告的每一筆寫了狀態行。
  - 最後一張票跑全書 `npm run verify`、`npm run test:verify` 與三個檢查,更新 pending.md、發布鏡像。
