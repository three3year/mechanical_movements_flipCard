# 03 — 畫一頁的選項:大小、切圖、外部網址

**What to build:** 截圖寬度預設 1800、可另給(上限 16384),高度依內容:畫完量內容的實際高度、截整頁。長邊超過 2000 px 時自動切成多張(`名稱-1.png`、`名稱-2.png`…):先量頁面上所有 img、canvas 的上下緣,切線只取沒有任何一張跨過的高度,每段取不超過 2000 的最遠切點;某張小圖本身超過 2000 就自己成一段,client 在那一行註明「會被縮小」。只有一段時輸出原檔名。外部網址(例如 507movements.com 的動畫頁)等呼叫時指定的秒數再截(有預設值)。見規格 User Stories 19–24。
