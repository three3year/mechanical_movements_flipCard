# 02 — 連結跳轉與返回

**What to build:** 審閱者點決策區問題裡的詞,頁面直接捲到後半的某一節或某張表格的某一列並高亮;看完按右下角浮動的「↑ 回到:<問題>」按鈕回到剛才的問題,或按參考區各節標題旁的「↑ 決策」回到決策區開頭。正本用標準 md 連結寫目標:節的錨點是標題到第一個「(」或「(」為止的文字,表格列是「節的錨點/該列第一欄的值」,第一欄同值的多列共用一個目標(捲到第一列、全部高亮)。腳本在產生頁面前檢查每個連結都找得到目標,斷連結或錨點重名就回傳錯誤、不輸出頁面。點連結由程式捲動,不改網址、不寫入瀏覽器歷史(claude.ai 內嵌框裡的「上一頁」不可靠)。細節見 [spec.md](../spec.md)。
