# 01 — 「決策在上」的鏡像 skill

**What to build:** 新增使用者層級(所有專案共用)的 review-mirror skill,之後所有審核關卡的 md 都用它發布鏡像。審閱者打開鏡像,頁首先看到決策區:待決事項(問題、選項、標「(建議)」的選項與各自代價)排在前面,已決事項排在區塊後段、一行灰掉的問題,點開看到完整原文;正本沒有 `## 需要你決定的` 時,決策區寫「沒有待決事項,只需核可整份」。正本其餘各節依原順序排在後半當參考資料。skill 附一支固定的 Node 腳本(入口:md 文字 + 顯示路徑 → 頁面 HTML 或錯誤清單;命令列讀檔、寫出 HTML,有錯誤時印出並以非零結束),SKILL.md 寫正本決策段的格式、發布步驟(查 mirrors.json、沿用或新建 artifact、寫回對應)。全域 CLAUDE.md 的「審閱 md → 附 artifact 鏡像」縮成指向這個 skill,完成條件改為「內容逐字一致,只有決策段移到頁首」。這一張還不做連結跳轉。格式與行為的細節見 [spec.md](../spec.md) 的 Implementation Decisions。

**Blocked by:** None — can start immediately
