# 維護者 2026-10-08 的決定:第 186、187 種重排凸柱,第 313 種照原圖重做

Status: done

**來源:** 第 86–507 種複查收尾後,維護者在待確認清單上的決定(2026-10-08),以及隨後的 grilling。維護者提供了第 313 種的運動影片(`C:\Users\three\我的電腦\oCam Video\turn.mp4`,一組彈簧止動式天文台計時器擒縱的立體動畫),要求理解原理後照原圖的樣子做。

## Problem Statement

待確認清單上有兩件維護者同意改、但模型還沒改的事:

- **第 186、187 種**(偏心桿脫鉤):搖臂上的凸柱和偏心桿畫在同一層,手柄把偏心桿抬起時,桿的上緣穿進凸柱;手柄抬桿的量是以指頭尖一點頂在凸柱上算的,指頭有寬度,尖端旁的邊角也伸進凸柱。兩張共 4 項「待確認」干涉豁免,接觸是演出的,不是由接觸算。
- **第 313 種**(天文台計時器擒縱):為了對上原文「齒 V 把通過彈簧向左按壓」,整組左右鏡像,擒縱輪跑到止動器右邊,和原圖不同。讀者切換插圖與模型時對不上。維護者看了實物的動畫後判定:原圖的配置本身就說得通(止動器往離開擒縱輪的方向退才放得開齒),要照原圖做。

## Solution

- **第 186、187 種**:凸柱伸到偏心桿前面一層(手柄指頭那一層),偏心桿抬起時從凸柱後面通過、碰不到;手柄拉多少、桿端抬多高,改由指頭的外形與凸柱相碰算。4 項待確認豁免移除。
- **第 313 種**:照原圖的配置重做,不再鏡像。擒縱輪在左、直立的止動器在右(下端 D 固定)、擺輪的滾子在右上。擺輪照原圖箭頭逆時針轉時,齒 V 把通過彈簧往右推、連止動器推離擒縱輪,鎖石放開一齒,放開的輪齒推滾子上的衝量叉瓦;擺輪返回時,齒 V 把通過彈簧往左壓彎而通過,止動器不動。原文的「向左」和原圖對不上,以原圖與實物動畫為準,寫進模型註解。

## Implementation Decisions

- **第 313 種**:沿用和第 291 種共用的彈簧止動式擒縱機構(由接觸算:止動器與通過彈簧鉸接、靠彈力回位;擒縱輪受固定力矩、被鎖石擋住)。第 313 種改成「整組轉 −90°、不鏡像」。共用模組的註解本來就寫著第 313 種是這個配置,鏡像是複查時為了對原文加的選項;第 313 種不再用它,沒有其他圖用時可移除。
- **第 313 種的轉向與方向**:擺輪的累計擺動照原圖箭頭,解鎖那一擺是逆時針;解鎖時齒 V 推通過彈簧的方向由幾何決定(往右、離開擒縱輪)。若不鏡像後幾何給出的解鎖方向、擒縱輪轉向或衝量的那一擺和這裡不一致,以原圖的配置與箭頭為準調整機構參數(V 的位置、彈簧與角的相對位置、衝量凹槽的方位),不回到鏡像。
- **第 313 種的判讀(推斷,寫進註解與待確認清單)**:插圖從 T 往上到 V 的直線是止動器往上伸的角(剛性,和止動器一體);彎線是通過彈簧,固定在止動器上、尖端靠在角的尖端。往右推時彈簧壓著角、帶動止動器;往左推時彈簧離開角、只壓彎彈簧。
- **第 313 種的外觀**:照原圖的比例與位置(擒縱輪約十五齒、在左下;大滾子有缺口、在右上;小滾子帶齒 V;止動器直立、下端 D 固定在座上)。不畫擺輪本體與游絲,只畫兩個滾子、擺輪軸與軸承。止動器靠住的擋止畫出來(推斷)、不標字母。字母照插圖:P 在衝量叉瓦、E 在鎖石,其餘 V、T、A、B、D 照插圖。
- **第 313 種的原文**:原文「向左按壓」與「擋止 E、P」照維護者決定以插圖為準,寫進模型註解;測試的說明引原文時註明方向以插圖為準。
- **第 186、187 種**:凸柱伸長到偏心桿前面一層,和手柄指頭同一層;偏心桿那一層沒有凸柱。手柄抬桿的量改成由指頭的外形(不是指頭尖一點)與凸柱的外形相碰算,用現有的接觸工具。第 186、187 種共用的脫鉤機構(偏心桿、鉤口)與第 188、189 種共用,第 188、189 種不受影響。
- **第 186、187 種的動力重演**:先試著宣告(偏心桿自由、靠自重搭在銷上,手柄照模型帶動);引擎做不出來時,維持「不適用」並寫明具體原因。
- **流程**:照第 86–507 種複查一族的流程:修 → 測試、實體驗證、截圖 → 更新第 7、17 族表格 → 更新待確認清單(推翻舊決定的建議那一列改成已照做、第 313 種與第 181、182 種相關敘述同步)與豁免清單 → 重新發布鏡像 → 提交。
- 模型本身仍依幾何關係連動(ADR-0001),物理引擎只用在實體驗證(ADR-0003)。

## Testing Decisions

- **三個檢查點,都是現有的**(維護者確認):
  1. **模型定義的測試**(`npm test`),從外部看 `pose()` 與模型匯出的運動函式:
     - 第 313 種放在擒縱章的測試檔:擺輪往箭頭方向(逆時針)擺時止動器往右(離開擒縱輪)、放走一齒、輪齒推著衝量叉瓦;返回時只有通過彈簧被壓彎,止動器與擒縱輪不動;一來一回擒縱輪轉一齒;鎖石、輪齒、叉瓦、齒 V、通過彈簧之間不穿入。前例:現有的第 291、313 種斷言。
     - 第 186、187 種放在引擎章的測試檔:手柄拉得越多桿端抬得越高、量由指頭與凸柱相碰算(不穿入);凸柱與偏心桿不在同一層、整個行程不重疊;拉到凹槽 a 時銷從鉤口中脫出。前例:現有的第 186–189 種脫鉤斷言。
  2. **實體驗證**(`npm run verify`):第 186、187、291、313 種的干涉、憑空連動、動力重演通過,沒有過時的豁免;第 186、187 種的 4 項待確認豁免移除。動到共用模組時跑全書。
  3. **插圖對照截圖**:模型預覽頁把插圖與模型並排,第 313 種取鎖住、解鎖、衝量、返回幾個相位;第 186、187 種取原圖位置與拉到凹槽 a。
- 瞬移用現有的掃描工具查,這四張沒有新的報出(刻意的除外)。
- 斷言要能指回原文的某一句(測試說明或註解引原文);第 313 種的方向以插圖為準,註明理由。

## Further Notes

- 實物動畫看到的原理(彈簧止動式):擺輪往一個方向擺時,小滾子上的解鎖石推通過彈簧,通過彈簧壓著止動器的角把止動器推開,鎖石放開擒縱輪;擒縱輪的齒接著推大滾子上的衝量石;止動器彈回鎖住下一齒。擺輪往另一個方向擺時,解鎖石只把通過彈簧撥開、止動器不動。動畫的視角是斜的、零件形狀和原圖不同,只取原理,不取外形。
