# 01 — 取景取樣抽成純函式、取景掃描工具、預設改成均勻取樣

**What to build:** 檢視器的取景取樣抽成不依賴 Three.js 的純函式(輸入主動件的種類——有範圍、一直轉、進程——與範圍或週期、目前值、段數,輸出要取樣的主動量),檢視器改用它。新增可重跑的取景掃描工具:對每張圖照檢視器的擺放規則,比較舊取樣、均勻取樣、段數加倍的均勻取樣三種外框,印出變大的比例;核心放在實體驗證那一側、有自己的 `test:verify` 測試,工具只印報告。用工具定預設段數(最小的段數,讓段數加倍時全書每張圖外框都不再變大超過 1%),預設改成均勻取樣,逐圖的段數選項拿掉(第 261、351 種那一行一起拿掉)。全書跑一次,報告附在 Comments,外框變大超過 2% 的圖對照票 02–07 的名單:名單外多出的,列在 Comments 並在收尾前另開票(每張最多 4 張圖);名單內不到 2% 的,記下數字即可。本票截圖確認第 105、209、261、351 種(第 105、209 種是 2026-10-12 量到變大最多的兩張;第 261、351 種拿掉逐圖選項後要照樣包住整個行程)。規格:`.scratch/model-audit-fixes-5/spec.md` User Stories 1–9。
