## Problem Statement

全書 507 張的實體驗證(0 個未豁免、122 項豁免)與測試都通過,但維護者看網頁或跑工具時仍會碰到下面幾類問題:

- **三題已決定、還沒做**:
  - 第 199 種換向那一下,要退出齒條的銷還在齒間深處,框架已反向,銷橫著掃過鄰齒的齒頂(穿入約 0.06–0.07),只靠「未修:」豁免帶著;它是第 86 種以後唯一的未修干涉。
  - 第 254 種的 Y 形叉齒平躺在輪緣面上,原圖是立在輪緣上、兩叉往軸向張開;直立鏈節套在平躺的叉齒外面,下半環穿進輪緣殼(半徑 1.39–1.46 對輪緣殼 1.37–1.55),畫面被輪緣蓋住、實體驗證量不到,輪廓外的齒也和原圖不像。
  - 取景只在範圍的兩端與中間(沒範圍的取一圈中的五處)取樣,零件在取樣點之間走得更遠的圖會中途出畫面。2026-10-12 量過,改成均勻取樣時有 27 張外框會變大超過 2%(第 105 種多 30%、第 209 種 22%、第 190 種 15%、第 152 種 13%……);目前只有第 261、351 種以逐圖的選項補救,其他圖要等有人發現。
- **實體驗證補盲點後報出的三項未修干涉**:第 132 種下壓板壓到最低時左導桿從方塊左緣穿入約 0.03;第 143 種橫移框架的圓柱沿水平桿滑動時和桿互相穿入 0.06;第 163 種撥叉的板升到高處那一段和機架的板互相穿入 0.05。
- **外形與洞**:第 400 種以前有 47 張的板件,洞的頂點落在外形外,或外輪廓自交。交給三角化之後,整個在外的洞會被丟掉、零件變成實心;自交的輪廓會多出一塊外形裡沒有的實體;一半在外的洞(多半是端頭沒畫圓的銷孔,或拿洞當缺口)三角化結果沒有定義,面積差幾個百分點。
  - 外輪廓自交:第 75、186、376 種。
  - 洞整個在外:第 190 種。
  - 洞一部分在外:其餘 43 張。
- **會伸縮的桿**:伸縮桿的檢查在第 400 種以前報出 9 張,原因有三種。
  - 真的要改模型:第 125 種兩層槓桿以「端點高度取平均」近似,`lower` 2.10–2.49、`upper` 2.73–2.90,畫面上桿明顯伸縮;第 369 種擺線沿頰板捲,長度差 0.01。
  - 本來就會伸縮、要宣告:彈簧畫成桿的第 235、239、240、287、360 種,與熱脹是原理的第 317、319 種補償擺。這類伸縮屬實,工具卻每次都報;第 401–507 種的第 416 種彈簧、第 478 種受熱伸長的管子也一樣。
  - 已決定接受:第 198 種直條 0.005 的伸縮,它的「可伸縮」標記沒有寫原因。

## Solution

先做跨圖的兩件事,再逐張修:

1. **取景**:把檢視器的取景取樣抽成不依賴 Three.js 的純函式,預設改成在範圍(或一圈、一個進程)內均勻取樣。另做一支可重跑的取景掃描工具,量全書每張圖的外框:新預設和舊取樣差多少,以及均勻取樣再加密時外框還會不會變大。外框變大的圖逐張截圖確認;拿掉第 261、351 種的逐圖選項。
2. **伸縮的宣告**:零件可以宣告「會伸縮」,並且必須寫原因。伸縮桿的檢查略過有宣告的零件,另外列出宣告與原因;有宣告卻沒寫原因的,檢查會報錯。彈簧、熱脹與第 198 種直條改用這個宣告;第 125 種原本的標記拿掉,改成真的定長。

逐張的修正:

- 第 199 種照原文「小齒輪只在不到一半的圓周上有銷」重排銷數、銷距與換向,讓最後一根銷推到高過齒頂才換向,未修豁免拿掉。
- 第 254 種照原圖把 12 個叉齒改成立在輪緣上的 Y,直立鏈節的下緣落在分岔處;環式鏈條加「直立鏈節抬高」的畫法,讓平躺鏈節貼著輪緣。
- 第 132、143、163 種重排幾何,讓干涉不再發生,未修豁免拿掉。
- 外形與洞的 47 張逐張修到檢查不再報出:銷孔的端頭畫圓、缺口改成外形的一部分、自交的輪廓重畫。
- 第 125 種照四連桿解成定長的桿;第 369 種的擺線長度照頰板的捲繞算到不變。

修完更新報告與 pending.md,重新發布鏡像。

## Implementation Decisions

- **範圍**:三題已決定的改動(第 199、254 種、全書取景)、pending.md 的三項未修干涉(第 132、143、163 種)、外形與洞的檢查在第 400 種以前報出的 47 張(含第 75、76、77、80 種,只修外形與洞)、伸縮桿的檢查在第 400 種以前報出的 9 張,以及第 198、416、478 種改用新的伸縮宣告。
- **維護者的決定**:
  - 2026-10-21,記在各報告與 `.scratch/model-audit/decisions-86-300.md`:第 199 種 (b) 照原文重排銷;第 254 種 (a) 照原圖重做叉齒;全書取景 (a) 預設均勻取樣;第 198 種 (a) 接受直條 0.005 的伸縮。
  - 同日在本規格之前另外決定:第 75–80 種的外形一起修;真的會伸縮的零件改成在零件上宣告並寫原因,工具不再報。
- **取景(跨圖,先做)**:
  - 檢視器的取樣抽成純函式模組(不 import Three.js,和實體驗證共用的擺放模組同類),輸入是主動件的種類(有範圍、一直轉、進程)、範圍或週期、目前值與段數,輸出取樣的主動量;檢視器改用它。預設段數由取景掃描工具定:取最小的段數,讓段數加倍時全書每張圖的外框都不再變大超過 1%。逐圖的段數選項拿掉(第 261、351 種的那一行一起拿掉)。
  - 新增取景掃描工具:對每張圖照檢視器的擺放規則,比較舊取樣、新預設、加密取樣三種外框,印出變大的比例。外框量法沿用維護工具已有的三角化(開發用依賴),核心放在實體驗證那一側、有自己的 `test:verify` 測試,工具本身只印報告,不影響 `npm run verify` 的成敗。
  - 外框變大超過 2% 的圖逐張截圖對照原圖;機構小到看不清的,用現有的「只以某些零件取景」或視角調整補救,寫明理由。
- **伸縮的宣告(跨圖,先做)**:
  - 零件的「可伸縮」改成帶原因的宣告。伸縮桿的檢查略過有宣告的零件,另外列出宣告與原因;有宣告卻沒寫原因的報錯。
  - 檢視器照舊依姿勢的兩端畫零件長度,不受影響。
  - 檢查的測試先寫失敗的例子:有原因的被略過、沒原因的報錯、沒宣告的照報。
- **第 199 種**:照報告第 199 種那一題 (b) 的說明重排。換向要由「最後一根銷高過齒頂」決定,不是照固定的角度瞬間換向;框架的速度、行程跟著重算,原圖的銷數與齒數重新對。原本「簡化齒形與瞬間換向」那類豁免照新的量測處理:剩下的照實寫原因,過時的拿掉。
- **第 254 種**:
  - 叉齒的尺寸配鏈節(推斷,註解寫明)。
  - 環式鏈條的「直立鏈節抬高」是路徑零件的新選項,只有第 254 種設;同一份擺法要給繪圖層、實體驗證的鏈條碰撞體與模型測試共用,不各寫一份。
  - 鏈條的相位照叉齒的位置算(延續 #254-1 的做法)。原本「鍊條中心線低於叉齒頂」的豁免照新的量測處理。
- **第 132、143、163 種**:照「原文 > 實物可行 > 插圖外形」選修法(導桿被方塊圍住或讓開、圓柱與桿同軸、撥叉的板讓開機架)。改了外觀的,在註解寫明偏離插圖。
- **外形與洞**:
  - 每一項都修到檢查不再報出:銷孔的端頭畫圓頭、洞當缺口的改成外形的缺口、自交的輪廓重畫。
  - 共用模組裡的輪廓(例如棘爪、錨形件、擺臂這類共用形狀)在模組裡改一次,用到的各圖一起重驗。
  - 外形一改,和它相碰的接觸要重新量,測試與驗證要照樣通過。
  - 第 75–80 種只改外形與洞。
- **伸縮桿**:
  - 第 125 種照四連桿解兩層槓桿的位置(做法同第 198 種的承載板)。
  - 第 369 種的擺線長度照頰板捲繞的弧長算。
  - 其餘照宣告處理。
- **推斷的零件與偏離插圖**:一律在模型註解標明;主動件或目標件換了零件的,登記到 `.scratch/recheck-86-507/tables/README.md` 的兩張表(這一輪預期沒有)。
- **紀錄**:

  - 外形、伸縮桿、未修干涉沒有報告條目,記在 pending.md 對應的段落。

## Testing Decisions

- **接縫**:
  - 沿用現有的三個:模型定義(`npm test`,對各圖匯出的 pose() 與接觸函式下斷言)、實體驗證(`npm run verify` 與它自己的 `npm run test:verify`)、維護工具的測試(`npm test` 裡的工具測試)。
  - 只新增一個:取景取樣的純函式模組,測試放進 `npm test`。
  - 取景掃描工具的核心測試放在 `test:verify`(它要用三角化,和外形檢查同一側)。
- **好的斷言**:
  - 對到原文的一句(例:「小齒輪只在不到一半的圓周上有銷」),或對到接觸(相碰的一對間隙接近 0、少轉一點就穿入、全程不穿入),或對到守恆(桿長、繩長不變)。
  - 不重複模型自己的公式、不只數零件的塊數。
  - 取景取樣的斷言對到規則:有範圍時兩端都在取樣裡、樣本等距;一直轉的涵蓋一圈;進程型涵蓋一個進程。
- **先寫失敗的測試再改**(TDD):
  - 第 199 種:換向那一刻要退出的銷已高過齒頂;全程銷與齒條的外形不穿入。
  - 第 254 種:直立鏈節下緣落在叉口分岔處、兩叉夾在兩側;平躺鏈節不穿進輪緣殼。
  - 第 125 種:兩根桿全程定長。
  - 第 132、143、163 種:那一對全程不穿入。
  - 伸縮宣告:沒原因的報錯。
  - 取景取樣:各種主動件的取樣規則。
  - 外形與洞的修正以檢查工具報 0 為準,不逐張寫測試;改到接觸面的,補量接觸的測試。
- **前例**:
  - 第 198 種「以兩根定長的桿與主框架鉸接」(四連桿解、桿長不變)。
  - #254-1 的「每一節直立鏈節都正對一個叉齒」(和畫面同一套擺法)。
  - 第 216 種換手由外形相碰決定、量交出與接手那一刻的間隙。
  - 外形檢查與伸縮桿檢查既有的工具測試。
- **每張票的完成條件**:
  - 該範圍 `npm run verify -- 圖號…` 通過、`npm test` 全過。
  - 外形與伸縮桿的檢查在該範圍不再報出已修的問題。
  - 每張改過的圖截四個相位(含斜後方)對照原圖。
  - 最後一張票跑全書 `npm run verify`、`npm run test:verify`,外形與伸縮桿的檢查全書 0 張,取景掃描工具的報告附在票裡。

## Further Notes

- **票的順序**:先做兩件跨圖的事(取景、伸縮宣告),再做逐張的修正,最後收尾。外形與洞的 47 張可以依圖號分幾張票平行做;用同一個共用輪廓的圖要放在同一張票。
