# 01 — 插圖總覽:進總覽看全部插圖,點一格打開卡片

**What to build:** 頁首的瀏覽方式切換鈕變成【依用途】【插圖總覽】【原書順序】。切到**插圖總覽**(用語見 `CONTEXT.md`)時,全書 507 張插圖依圖號排成一整面圖塊、不分頁;點一格就以原書順序打開該插圖所在條目的卡片並選中那張插圖。導覽邏輯是瀏覽模組的第三種瀏覽方式,頁面只照 `where()` 畫(見規格 `.scratch/figure-overview/spec.md` 的 Implementation Decisions)。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 瀏覽模組:`setMode("overview")` 進總覽,不改變目前所在的卡片(條目與選中的插圖),返回堆疊清空;從用途瀏覽進來時照現行規則記下所在用途大類
- [x] 瀏覽模組:總覽中 `where()` 的 `mode` 是 `"overview"`,並回答全部插圖的圖號(依圖號排,507 個)
- [x] 瀏覽模組:點一格的動作(例如 `open(no)`)只在總覽中有效:切到原書順序、落在該圖所在條目、選中該圖、返回堆疊清空;不存在的圖號不動並回答失敗
- [x] 瀏覽模組:從總覽 `setMode("book")`、`setMode("use")` 以進總覽前的卡片為起點,落點和從卡片直接切換相同
- [x] 瀏覽模組:沒有用途檔時仍可進總覽、點格
- [x] 頁面:切換鈕三個、依序【依用途】【插圖總覽】【原書順序】,標示目前所在;用途檔載入失敗時仍顯示【插圖總覽】【原書順序】兩個
- [x] 頁面:總覽是自動填滿的方格(約 120 px 見方),插圖等比縮放置中、延遲載入,格子上只有圖;替代文字與工具提示是「第 N 種」
- [x] 頁面:總覽中隱藏用途頁籤、翻頁列、跳到圖號、返回鍵與卡片;鍵盤 ← → 與手機滑動不翻頁;頁尾是「插圖總覽 · 共 507 圖」
