# 01 — 一件掃描工具

**What to build:** 維護者能用一支工具掃出「同一零件各塊不相連」:比照找伸縮桿的那支工具,對每個零件的各塊(含 pieces 的位置、厚度與轉角)算外接盒,和其他塊都不相交的就報;可指定圖號;只印報告,不讓實體驗證失敗(不動 ADR-0003)。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 工具可對全書或指定圖號執行,報出零件 id、懸空的那一塊與最近的間隙
- [x] 對第 186–250 種跑一次,報出的和六份報告記的「一件」問題一致(例:#215-2、#216-2、#217-1、#232-1、#232-2、#235-1、#241-2、#208-1、#210-2、#198-1);不一致的在本票說明原因(外接盒相交但其實不相連的,或刻意的分件)
- [x] 工具自己的測試(合成的相連 / 不相連零件各一),放在現有測試或驗證測試裡
- [x] `CLAUDE.md` 開發一節與 `docs/agents/model-audit.md` 第 3 類寫上用法
- [x] 以獨立暫存區提交
