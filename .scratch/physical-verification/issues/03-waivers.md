# 03 — 豁免

**What to build:** 維護者可以把實體驗證報出、但經判斷可以接受的問題寫成豁免,放在該模型的定義裡並註明原因;有豁免的問題不再讓指令失敗,但隨時可以列出全書所有豁免與原因。

**Blocked by:** 01

**Status:** ready-for-agent

規格:`.scratch/physical-verification/spec.md`;用語見 `CONTEXT.md`(實體驗證、干涉、憑空連動、動力重演、豁免);相關決定見 ADR-0001、ADR-0003。

- [ ] 模型定義可帶一份豁免清單;每項指明檢查種類、涉及的零件、原因
- [ ] 有豁免且有原因的問題不出現在未豁免清單,指令不因它失敗
- [ ] 沒寫原因的豁免無效,問題照樣報出
- [ ] 豁免只放過它指明的那一個問題,同一模型的其他問題照報
- [ ] 豁免的對象已經不存在問題(修好了、零件改名了)時,報為過時的豁免,指令以失敗結束
- [ ] 指令可列出全書所有豁免與原因
- [ ] 登記表完整性測試檢查:豁免必有原因、涉及的零件存在
- [ ] 以上各有合成模型測試
