# 02 — 干涉涵蓋所有零件與全書

**What to build:** 干涉檢查涵蓋全書實際用到的每一種零件,維護者可以對全書 507 個模型跑完並得到一份依圖號排序的報告。嚙合的齒輪、齒條、蝸桿以實際齒形判斷(正常嚙合不報,齒咬進對方實體才報);皮帶、繩、鍊、桿等線狀零件以沿路徑的粗細體積參與(貼著輪不報,穿過其他實體才報)。

**Blocked by:** 01

**Status:** done

- [x] 所有剛體零件種類(含連桿、齒輪、內齒輪、傘齒輪、旋轉體、球、蝸桿、齒條、彈簧等)都能建出碰撞形狀;新增零件種類時自動沿用繪圖層的形狀
