# 48 — 收尾

**What to build:** 全書查修完成後的交付:確認全書實體驗證通過,把實體驗證寫進專案的日常流程,移除被它取代的舊掃描工具,並把待確認清單與全書豁免清單整理成維護者最後看網頁時用的導引。

**Blocked by:** 07–47

**Status:** ready-for-agent

規格:`.scratch/physical-verification/spec.md`;用語見 `CONTEXT.md`(實體驗證、干涉、憑空連動、動力重演、豁免);相關決定見 ADR-0001、ADR-0003。

- [ ] 全書 507 張的實體驗證通過(沒有未豁免的問題、沒有過時的豁免);實體驗證自己的測試與既有測試都通過
- [ ] 每個靠接觸或重力運作的模型都有動力重演的宣告,或有註明原因的豁免
- [ ] 專案說明寫明「改動或新增模型後要跑實體驗證」與指令名稱
- [ ] 手動驗證清單中與實體驗證重複的抽查項目,改為指向這個指令
- [ ] 被取代的兩支掃描工具(同平面穿透、看不到相連處)移除;找瞬移與沒有目標件的那支保留
- [ ] 待確認清單彙整完成:依圖號排序,每項有疑點、選了什麼、為什麼,供維護者優先檢視
- [ ] 全書豁免清單(圖號、檢查種類、零件、原因)附在本票的 Comments
- [ ] 提交為一個提交(主分支,不推送)
