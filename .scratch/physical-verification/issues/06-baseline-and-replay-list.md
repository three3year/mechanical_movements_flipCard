# 06 — 全書基線與動力重演名單

**What to build:** 把完整的實體驗證對全書跑一次,得到一份基線:各章各有多少干涉、憑空連動的問題。把明顯是工具誤報的類型修在工具上(不是用豁免蓋掉),定出全書共用的容許值,並列出全書要做動力重演的模型名單。完成後提交工具,後續的查修票以這份基線為起點。

**Blocked by:** 03、04、05

**Status:** ready-for-agent

規格:`.scratch/physical-verification/spec.md`;用語見 `CONTEXT.md`(實體驗證、干涉、憑空連動、動力重演、豁免);相關決定見 ADR-0001、ADR-0003。

- [ ] 全書 507 張跑完,基線報告(各章、各檢查種類的問題數與涉及的圖號)記在本票的 Comments
- [ ] 抽查各類問題,屬於工具誤報的類型已在工具上修正並補測試;全書共用的容許值定案並記錄理由
- [ ] 動力重演名單定案:由用到接觸與落下共用工具的模型出發,加上逐章瀏覽判定靠接觸或重力運作的(棘輪棘爪、止回爪、凸輪從動件、擒縱、落錘與搗桿、彈回的手柄、自重落下的零件等);名單與每張的理由記在 Comments
- [ ] 建立待確認清單與各批紀錄的存放位置與格式(圖號、疑點、選了什麼、為什麼)
- [ ] 既有測試與實體驗證自己的測試都通過
- [ ] 工具提交為一個提交(主分支,不推送)
