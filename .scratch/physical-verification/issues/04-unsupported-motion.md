# 04 — 憑空連動

**What to build:** 實體驗證加上第二項:每個會動的零件,在它實際在動的姿勢裡,必須有實體一路連回主動件,而且有支撐;連不回去或懸空的報為憑空連動,並附上它離最近實體的距離。檢查是三維的,所以前後兩層之間少了軸或銷會被報出。

**Blocked by:** 02

**Status:** ready-for-agent

規格:`.scratch/physical-verification/spec.md`;用語見 `CONTEXT.md`(實體驗證、干涉、憑空連動、動力重演、豁免);相關決定見 ADR-0001、ADR-0003。

- [ ] 以零件實體之間的間隙是否在容許值內建立相連圖(不是包圍球估算);線狀零件與它貼著的輪算相連
- [ ] 合成模型測試(成對):兩個齒輪隔著空隙一起轉 / 嚙合;前後兩層的輪同步轉但中間沒有軸 / 有軸;懸空自轉的輪 / 裝在軸上
- [ ] 掛在繩上的重物、皮帶帶動的輪不報
- [ ] 主動件本身不需要來源;並排變體各自連回自己的抓取處,不互相誤報
- [ ] 虛擬主動件的模型中,模型定義可標記直接受流體或力推動的零件為外力來源,這些零件不報;登記表測試檢查標記指向存在的零件
- [ ] 間歇接觸的零件只在它實際在動的姿勢需要有接觸;停住時沒接觸不報
- [ ] 問題上寫出離最近實體的距離、主動量、狀態
- [ ] 豁免對憑空連動同樣有效
