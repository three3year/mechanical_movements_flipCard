## code review 留下、還沒處理的

- 沒有 `replay` 宣告的模型無法寫動力重演的豁免(會被報成過時)。
- 動力重演只比各預期事件當下的轉角與位置,沒有另外檢查先後順序;`replay.ignore`、`seconds`、`tolerance` 不要求寫原因。
