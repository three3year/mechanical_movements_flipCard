# 待確認清單(實體驗證與全書查修)

實作者拿不準、自己判斷後先做的地方。維護者看網頁時優先看這裡。每項:圖號、疑點、選了什麼、為什麼。

## 工具的判定規則(全書共用)

- **軸、銷、輪轂、球接頭裝在沒畫出來的孔裡不算干涉。** 規格 #56 希望固定零件之間的簡化畫法一律用豁免處理。選了什麼:圓柱(或球)伸進別的零件時,只要兩者之中有會動的、而且圓柱的軸線在對方座標裡始終是同一條(繞自己的軸轉、沿軸滑),就視為軸承 / 鉸接 / 導桿,不報;軸線會移動的(銷掃過實體)照報;**兩個都固定不動的仍照報,要寫豁免**(符合 #56)。為什麼:全書的輪、槓桿、連桿幾乎都沒畫軸孔,逐一寫豁免會有上千條內容相同的豁免,反而蓋住真正的問題。
- **一起動、彼此沒有相對運動的兩個零件視為同一個剛體,重疊不報**(活塞與活塞桿、臂與臂端的球)。為什麼:等同「同一個零件自己的各部分之間不查」。
- **憑空連動不要求每個姿勢都連回主動件。** 選了什麼:會動的零件之間,只要在某個有在動的姿勢相碰,就算有一條帶動的邊;從主動件沿這些邊走得到的都算有實體帶動。為什麼:被頂起再自己落下的零件(落板、棘爪、擺)落下時本來就沒碰著主動件。
- **轉動記號與板面刻線不算實體**;線狀零件以中心線穿進實體多深算干涉(貼著輪面不算),開放路徑繫在零件上的那一段不算。
- **全書共用容許值**:穿入深度 0.03、相連的間隙 0.03(模型單位;一般零件尺寸 1–3)。理由見票 06。
