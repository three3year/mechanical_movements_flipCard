## 這一輪新增、需要確認的判定

第一輪的規則不變。這一輪為了少寫內容相同的豁免,多了下面幾條;不同意的話告訴我,我改回逐張豁免。

- **螺桿的螺紋轉在沒畫出來的螺孔裡不算干涉。** 螺紋和螺桿的芯一樣當成軸:它的軸線在對方座標裡始終是同一條(螺帽沿螺桿滑、螺桿在軸承座裡轉)才算。蝸桿對蝸輪不適用(蝸輪轉動時蝸桿的軸線在它的座標裡會移動),仍照報。
- **長條方桿沿自己的長軸在導座裡滑動不算干涉。** 長度至少是寬、厚三倍的方塊,軸線在對方座標裡始終是同一條才算(在沒畫出方孔的導座裡滑動的桿);橫著掃過別的零件、或繞樞軸擺動的桿仍照報。
- **動力重演的豁免可以用 `at` 指明是哪一個預期事件**(主動量),只放過那一個;沒寫 `at` 就是該零件的每個預期事件(處理第一輪 code review 留下的第一項)。
- **`powered`(外力來源)用在幾個不是虛擬主動件的模型上**:第 379 種的進給螺桿(由操作的人另外轉動)、第 466、467 種被水頂起的柱塞 / 圓筒(液壓傳動)、第 471、472 種被空氣墊 / 壓縮空氣帶動的錘。這些零件和主動件之間本來就沒有實體相連。
- 干涉的訊息多附了「沿哪個方向分得開」(修的時候知道該往哪邊挪)。

## code review 留下、還沒處理的

- 沒有 `replay` 宣告的模型無法寫動力重演的豁免(會被報成過時)。
- 動力重演只比各預期事件當下的轉角與位置,沒有另外檢查先後順序;`replay.ignore`、`seconds`、`tolerance` 不要求寫原因。
- 線狀零件對任何實體都以中心線算穿入(規格只說纏繞或掛著的輪相貼不算);線狀零件彼此之間不查干涉。
- `lathe`(旋轉體)零件的 `pieces` 繪圖層不會畫出來(第 457–459 種的水桶提把原本因此沒畫出來,已改成群組);其他用到的地方沒有逐一查。
- 取樣與預設速度的規則在 `verify/sampling.js` 與 `viewer/viewer.js` 各有一份(未抽成共用)。
- 提交仍然不是「每章一個提交」:這一輪依處理的批次提交,工具規則的調整夾在查修的提交裡。
