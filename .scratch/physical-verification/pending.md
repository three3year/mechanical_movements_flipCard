## 工具的判定規則(全書共用;與規格不同處請確認)

- **軸、銷、輪轂、套筒、球接頭裝在沒畫出來的孔裡不算干涉。** 規格 #56 希望固定零件之間的簡化畫法一律用豁免處理。選了什麼:圓柱(或球)伸進別的零件時,只要兩者之中有會動的、而且圓柱的軸線在對方座標裡始終是同一條(繞自己的軸轉、沿軸滑),就視為軸承 / 鉸接 / 導桿,不報;軸線會移動的(銷掃過實體)照報;兩個都固定不動的仍照報(符合 #56)。為什麼:全書的輪、槓桿、連桿幾乎都沒畫軸孔,逐一寫豁免會有上千條內容相同的豁免。
- **鉸接處互相套著的軸眼不算干涉**:鉸接軸的軸線同時穿過的兩塊,在軸周圍的重疊不報(連桿端頭疊在槓桿上)。
- **一起動、彼此沒有相對運動的兩個零件視為同一個剛體,重疊不報**(活塞與活塞桿、臂與臂端的球)。
- **憑空連動不要求每個姿勢都連回主動件**:會動的零件之間,只要在某個有在動的姿勢相碰,就算有一條帶動的邊。為什麼:被頂起再自己落下的零件(落板、棘爪、擺)落下時本來就沒碰著主動件。
- **轉動記號與板面刻線不算實體**;線狀零件以中心線穿進實體多深算干涉(貼著輪面不算),開放路徑繫在零件上的那一段不算;沒有形體的標籤群組不查。
- **容許值**:穿入深度 0.03、相連的間隙 0.03(模型單位;一般零件尺寸 1–3)。
- **外力來源(`powered`)是我依零件名稱與機構常理標的**(活塞、水車的輪、調速器的球、擺錘、重物、浮筒……),沒有逐張對照原文;標錯的話憑空連動會漏報或誤報。

## code review 留下、還沒處理的

- 動力重演的豁免目前以零件比對,同一個零件的幾個預期事件會被同一項豁免一起放過(規格 #53 要求只放過那一個問題);沒有 `replay` 宣告的模型也無法寫動力重演的豁免(會被報成過時)。
- 動力重演只比各預期事件當下的轉角與位置,沒有另外檢查先後順序;`replay.ignore`、`seconds`、`tolerance` 不要求寫原因。
- 線狀零件對任何實體都以中心線算穿入(規格只說纏繞或掛著的輪相貼不算);線狀零件彼此之間不查干涉。
- `powered` 在非虛擬主動件的模型也有效,登記表測試沒有限制。
- 取樣與預設速度的規則在 `verify/sampling.js` 與 `viewer/viewer.js` 各有一份(未抽成共用)。
- 提交沒有做到「每章一個提交」:後段幾章併在同一個提交,工具的規則調整也夾在查修的提交裡。
- 1020 項「待確認」豁免不符合詞彙表對豁免的定義(「經判斷可以接受」);它們是待辦清單,不是判斷過的結論。
