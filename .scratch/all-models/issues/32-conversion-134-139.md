# 32 — 運動轉換與應用：鼓輪、偏心輪與內齒條

**What to build:** 為第 134、135、136、137、138、139 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

**插圖：**

- 第 134 種：藉由繩索或皮帶將均勻的圓周運動轉換為直線運動，該繩索或皮帶會繞著鼓輪一圈或多圈
- 第 135 種：第 91 種所示三角形偏心輪的變形，曾用於巴黎鑄幣廠（Paris Mint）的蒸汽引擎上
- 第 136 種：凸輪輪（cam-wheel）——圖中所示為側視圖——其輪緣被做成具齒狀，或任何所需的輪廓形狀
- 第 137 種：用於在法國蒸汽引擎中驅動滑閥（slide-valve）的膨脹偏心輪（Expansion eccentric）
- 第 138 種：當底部的凸輪轉動時，會將變速的交替直線運動傳遞給靠在其上的桿
- 第 139 種：由矩形框架承載的內齒條，可以在該框架內於一定距離範圍內上下自由滑動，如此一來小齒輪便能與齒條的任一側嚙合
