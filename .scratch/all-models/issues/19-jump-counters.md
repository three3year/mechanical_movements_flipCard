# 19 — 間歇與棘輪運動：跳躍式計數

**What to build:** 為第 63、64、66、67、76 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

**插圖：**

- 第 63 種：跳躍式或稱間歇式的旋轉運動，用於計量器（meters）和轉數計數器（revolution-counters）
- 第 64 種：另一種跳躍運動的配置方式
- 第 66 種：為第 64 種的變形；一個重物 D 連接於固定在蝸輪軸上的搖臂上，取代原本的彈簧與凸輪來使用
- 第 67 種：為第 64 種的另一種變形；一個重物或稱擺錘（tumbler）E 固定於空心軸上，用來取代彈簧與凸輪，並與蝸輪軸中的銷 C 組合運作
- 第 76 種：為另一種用於登錄或計算轉數的裝置
