# 01 — 登記表改為按需載入

**What to build:** 開頁時只載入「圖號 → 定義所在」的清單，不再載入任何模型定義；讀者切到某張插圖的模型時，才載入那一張的定義。第一章既有 23 個模型遷移到新的登記方式，讀者看到的行為完全不變：有模型的卡片照樣出現「插圖 / 模型」切換與圖號小頁籤，模型模式記憶、交互參照跳轉都照舊。單一模型定義載入失敗時，圖片區顯示簡短提示，插圖與文字照常可看。

這張票是之後所有模型票的前置（make the change easy）：之後每新增一個模型，只要寫定義、在清單登記一行。

**Blocked by:** None — can start immediately
