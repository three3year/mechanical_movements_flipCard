# 66 — 平行運動與引擎：平行尺

**What to build:** 為第 322、323、324、325、349 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

平行尺的模型重現使用時的動作（推動尺葉、畫出平行線），用作圖軌跡。

**插圖：**

- 第 322 種：一種非常方便的平行尺（parallel ruler）繪圖結構，製作方式是將一個四邊形沿對角線切開，形成兩個直角三角形 A 和 B
- 第 323 種：平行尺，由一根簡單的直尺 B，加上附屬的輪軸 C，以及一對輪 A、A 所組成
- 第 324 種：複合平行尺，由兩根簡單的尺 A、A 所組成，透過兩根交叉的臂連接，兩臂於其長度的中點處以樞軸相連，每根臂的一端以樞軸連接於其中一根尺上，另一…
- 第 325 種：由兩根簡單的尺 A、B，透過兩根以樞軸擺動的臂 C、C 連接而成的平行尺
- 第 349 種：另一種形式的平行尺
