# 21 — 間歇與棘輪運動：棘爪與雙棘爪

**What to build:** 為第 73、77、78、79、80 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

**插圖：**

- 第 73 種：驅動輪 D 上固定著一根彎曲的彈簧 B；另一根彈簧 C 則連接於固定的支撐座上
- 第 77 種：槓桿 C 圍繞著中心點或稱支點 A 的振動運動，透過兩個交替作動的棘爪，產生輪 B 的旋轉運動
- 第 78 種：為第 77 種的變形
- 第 79 種：桿 B 的往復直線運動，透過裝設於振動徑向臂 C、C 兩端的棘爪，使具棘齒面的輪 A 產生近乎連續的旋轉運動
- 第 80 種：藉由槓桿 C 的振動，透過交替落入槽形齒條桿 A 齒中的兩根鉤形棘爪，將直線運動賦予具槽形的桿 A
