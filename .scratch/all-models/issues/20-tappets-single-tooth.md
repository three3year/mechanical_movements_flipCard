# 20 — 間歇與棘輪運動：撥爪與單齒間歇

**What to build:** 為第 65、68、69、70、71、74 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

**插圖：**

- 第 65 種：左側的圓盤或稱輪 C，是驅動輪，其上固定著撥爪（tappet）A
- 第 68 種：驅動輪 B 上唯一的齒 A 作用於輪 C 的凹槽中，並使該輪 C 於每一次 C 完整旋轉時，都轉動一個凹槽的距離
- 第 69 種：B——具有單一齒的小輪——為驅動端，而輪 A 上齒與齒之間的圓周部分，則在小輪的齒未作動的期間，起到鎖定或擋止的作用
- 第 70 種：驅動輪 C 具有一圈輪緣（rim，以虛線示意），該輪緣外側在撥爪 B 未與凸柱接觸的期間，作為另一個輪 A 上凸柱的軸承與擋止之用
- 第 71 種：驅動輪 B 的內側圓周（以虛線示意）作為鎖定機構，輪 C 上的凸柱中會有兩根靠在其上，直到撥爪 A 撞擊到其中一根凸柱時，其下方的下一根凸柱…
- 第 74 種：藉由缺齒式斜齒輪（mutilated bevel-gear）C，將方向相反的均勻間歇旋轉運動賦予斜齒輪 A 和 B
