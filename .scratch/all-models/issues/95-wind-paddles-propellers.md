# 95 — 風力、船舶與起重：螺旋葉片、風車、明輪與螺旋槳

**What to build:** 為第 484、485、486、487、488、489 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

風車屬進程型虛擬主動件，風以流體示意（空氣）呈現；明輪與螺旋槳靠引擎轉動時讓讀者直接抓輪或軸，水流用流體示意。

**插圖：**

- 第 484 種：繞在圓筒上的螺旋葉片，用於將風或水流的運動轉換為旋轉運動
- 第 485 種：普通的風車（wind-mill），說明風直接作用於傾斜帆面上而產生圓周運動的原理
- 第 486 種：垂直式風車的平面圖
- 第 487 種：普通的明輪（paddle-wheel），用於推進船隻；輪的旋轉使槳板向後推壓水，從而產生船隻的前進運動
- 第 488 種：螺旋槳（Screw propeller）
- 第 489 種：垂直槳板明輪（Vertical bucket paddle-wheel）
