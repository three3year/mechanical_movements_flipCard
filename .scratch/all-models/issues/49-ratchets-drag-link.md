# 49 — 棘輪與擒縱：棘輪、死點連桿與拖曳連桿

**What to build:** 為第 225、226、230、231、232 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

**插圖：**

- 第 225 種：由承載棘爪的搖臂之振動運動所產生的棘輪之間歇圓周運動
- 第 226 種：此運動裝置設計用來讓相同直徑與相同齒數的齒輪達到雙倍速度——這是一項曾被普遍認為不可能達成的結果
- 第 230 種：圓周運動轉換為圓周運動
- 第 231 種：拖曳連桿運動（Drag-link motion）
- 第 232 種：藉由振動搖臂 B，將間歇的圓周運動傳遞給齒形輪
