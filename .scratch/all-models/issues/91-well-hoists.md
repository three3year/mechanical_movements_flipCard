# 91 — 水車與泵：汲水、舀水斗、擺動水槽與平衡泵

**What to build:** 為第 457、458、459、460、461、465 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

**插圖：**

- 第 457 種：從深度不大的水井汲水的常見方式
- 第 458 種：常見的汲水用皮帶輪與水桶；將空桶往下拉，以抬起盛滿水的水桶
- 第 459 種：用於水井的往復式升降機
- 第 460 種：Fairbairn 的舀水斗（bailing-scoop），用於將水抬升短距離
- 第 461 種：擺或擺動式水槽，藉由其擺動運動來抬升水
- 第 465 種：平衡泵（Balance pumps）

**Blocked by:** 03 — 連桿閉合：第 92 種普通曲柄運動；07 — 進程型虛擬主動件與流體示意：第 430 種上射式水車
