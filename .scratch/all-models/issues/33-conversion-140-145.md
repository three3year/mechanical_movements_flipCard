# 33 — 運動轉換與應用：肘節、帶鋸、懶剪與樑

**What to build:** 為第 140、141、142、143、144、145 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

**插圖：**

- 第 140 種：為衝床機（punching machine）所配置的肘節接頭（toggle-joint）
- 第 141 種：無端帶鋸（Endless-band saw）
- 第 142 種：用於變化橫移導桿長度的運動裝置，該導桿在絲織機械中用來引導絲線繞到線軸或紗管（bobbins）上
- 第 143 種：將圓周運動轉換為交替直線運動
- 第 144 種：一種交叉槓桿系統，稱為「懶剪（Lazy Tongs）」
- 第 145 種：樑（beam）的往復曲線運動，會給予曲柄與飛輪連續的旋轉運動

**Blocked by:** 02 — 齒輪咬合：第 24、34 種；03 — 連桿閉合：第 92 種普通曲柄運動；26 — 螺旋機構：螺桿與螺帽
