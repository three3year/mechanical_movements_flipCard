# 22 — 間歇與棘輪運動：傾動錘、缺齒輪與凸輪間歇

**What to build:** 為第 72、81、82、83、84、85 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

**插圖：**

- 第 72 種：為一種傾動式錘子運動（tilt-hammer motion），凸輪或稱推板輪（wiper-wheel）B 每旋轉一圈會將錘子 A 抬起四次
- 第 81 種：藉由缺齒式正齒輪 A 的連續旋轉，將交替方向的直線運動賦予齒條桿 B；當齒輪 A 的齒脫離齒條時，螺旋彈簧 C 會將該桿推回其原本位置
- 第 82 種：當運動施加於兩個踏板 D 時，透過振動臂 B 及其上附著的棘爪，將近乎連續的運動傳遞給棘輪 A
- 第 83 種：藉由兩個具棘齒的弧形板 C，將近乎連續的旋轉運動賦予輪 D，其中一個弧形板作用於棘輪 D 的一側
- 第 84 種：雙齒條框架 B 懸掛於桿 A 上
- 第 85 種：藉由帶有兩個凸輪或稱推板的軸的連續旋轉，將間歇性的交替直線運動賦予桿 A，該等凸輪作用於桿上的凸起 B，藉此將桿抬起

**Blocked by:** 02 — 齒輪咬合：第 24、34 種；04 — 凸輪：第 96 種心形凸輪；05 — 棘輪與間歇接觸：第 75 種
