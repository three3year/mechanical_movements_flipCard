# 52 — 接頭與器具：皮帶輪與鏈輪的種類

**What to build:** 為第 243、254、255、256、257、258、259 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

第 255–259 種本身是靜止的器具，模型重現被皮帶 / 繩帶動旋轉的動作，並在定義中註明為推斷。

**插圖：**

- 第 243 種：圖示為一種透過皮帶輪與皮帶，將動力從一根水平軸傳遞至兩根垂直軸的方式
- 第 254 種：用來以鏈條驅動或被鏈條驅動的鏈輪（sprocket-wheel）
- 第 255 種：用來以扁皮帶（flat belt）驅動或被扁皮帶驅動的帶凸緣皮帶輪
- 第 256 種：用於扁皮帶的普通皮帶輪
- 第 257 種：用於圓形皮帶的凹槽皮帶輪
- 第 258 種：用於圓形皮帶、表面平滑的 V 形槽皮帶輪
- 第 259 種：V 形槽皮帶輪，其溝槽刻有凹紋以增加皮帶的附著力
