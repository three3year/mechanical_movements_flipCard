# 27 — 螺旋機構：溝槽凸輪與螺旋應用

**What to build:** 為第 106、107、108、110、112 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

第 106–107 種是同一條目的兩張圖，先看原圖判斷是同一機構的不同視圖，還是不同機構。

**插圖：**

- 第 106 種（條目 106–107）：均勻的往復直線運動，由開槽凸輪的旋轉運動所產生
- 第 107 種（條目 106–107）：均勻的往復直線運動，由開槽凸輪的旋轉運動所產生
- 第 108 種：由圓筒的均勻旋轉運動所產生的均勻往復直線運動，該圓筒上切有反向的螺紋或溝槽，這些螺紋或溝槽必然於每一圈中相交兩次
- 第 110 種：將均勻的圓周運動轉換為均勻的直線運動；用於捲線機（spooling-frames）中，用來引導或導引線繞到線軸（spools）上
- 第 112 種：波斯鑽（Persian drill）
