# 55 — 接頭與器具：測功計、縮放圖器與斜槽臂

**What to build:** 為第 244、246、252、273 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

第 246 種縮放圖器用作圖軌跡。

**插圖：**

- 第 244 種：測功計（dynamometer），即一種用於測定任何動力來源所輸出之有用功大小的儀器
- 第 246 種：圖示為一種用於複製、放大及縮小平面圖等的縮放圖器（pantograph）
- 第 252 種：A 和 B 為兩個滾子，需要在溝槽 C 內以相同幅度來回移動
- 第 273 種：將直線運動轉換為直線運動
