# 81 — 繪圖儀器：中心引導器、比例圓規、等分規與記錄水平儀

**What to build:** 為第 408、409、410、411 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

**插圖：**

- 第 408 種：中心引導器（Centrolinead），用於將直線朝一個無法到達或極不方便的點描繪；主要用於透視圖中
- 第 409 種：比例圓規（Proportional compasses），用於將圖畫以較大或較小的比例進行複製
- 第 410 種：等分規（Bisecting gauge）
- 第 411 種：測量員用的自動記錄水平儀（Self-recording level）
