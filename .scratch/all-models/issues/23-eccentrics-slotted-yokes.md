# 23 — 曲柄與凸輪：偏心輪與開槽軛

**What to build:** 為第 89、90、91、93、94、98 種建立模型並登記。讀者在這些卡片切到模型後，可以拖動主動件（或虛擬主動件滑桿）帶動整個機構，看到原文描述的運動。先讀每張原圖與原文，決定主動件、零件配置、狀態按鈕、字母標籤與讀數。

**插圖：**

- 第 89 種：一般用於曲柄軸（crank-shaft）上的偏心輪（eccentric），用於將往復直線運動傳遞給蒸汽引擎的閥門，有時也用於抽水
- 第 90 種：為第 89 種的變形；以一個延伸的軛狀件（yoke）取代環形皮帶，以避免必須讓運作於固定導軌內的桿產生振動運動
- 第 91 種：三角形偏心輪，可產生間歇性的往復直線運動，在法國曾用於蒸汽引擎的閥門運動裝置
- 第 93 種：曲柄運動，其曲柄手腕（crank-wrist）於一個開槽軛狀件（slotted yoke）內作動，藉此省去搖動式連桿或稱抽送桿（pitman…
- 第 94 種：可變曲柄（Variable crank），由兩片旋轉於同一中心的圓形板組成
- 第 98 種：藉由圓形圓盤的旋轉產生不規則的振動運動，該圓盤上固定著一根曲柄銷（crank-pin），該銷在振動臂上所切出的一條無端（環形）溝槽內作動

**Blocked by:** 03 — 連桿閉合：第 92 種普通曲柄運動；04 — 凸輪：第 96 種心形凸輪
