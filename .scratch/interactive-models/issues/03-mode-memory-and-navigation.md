# 03 — 模式記憶與導覽

**What to build:** 讀者切到模型模式後，翻頁或切章都會停在模型模式。翻到沒有模型的卡片時顯示插圖，再翻到有模型的卡片時自動回到模型。點說明文字裡的「第 N 種」交互參照跳過去，以及按「返回」回來時，都維持模型模式。3D 函式庫載入失敗時顯示簡短提示，插圖和文字照常可看。切換時不閃白。
