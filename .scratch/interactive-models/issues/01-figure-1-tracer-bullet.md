# 01 — 第 1 種模型全線打通

**What to build:** 讀者翻到第 1 種的卡片時，圖片區會出現「插圖 / 模型」切換。切到模型後，看到一個線稿風的 3D 開口皮帶傳動模型：兩個皮帶輪同向慢速轉動，皮帶上的間隔記號跟著移動。這張任務要把整條路徑都接通，包括模型定義（純運動學，與繪圖分離）、以圖號為鍵的模型登記表、第一組 Node 測試、延遲載入 Three.js、線稿風繪圖、自動慢速播放，以及在模型模式下停用圖片區的點擊與滑動翻頁。規格見 `../spec.md`，連動方式遵循 ADR-0001（運動學，不用物理引擎）。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 模型定義是可同時被瀏覽器與 Node 載入的 ES module，不依賴 Three.js 或 DOM；提供圖號、零件、主動件（旋轉型）以及 `pose(driverValue, stateId)`
- [x] `pose` 回傳每個零件的姿勢、皮帶行進相位與讀數清單（第 1 種讀數為空）
- [x] 模型登記表以圖號為鍵；卡片只在條目內有已登記的插圖時才顯示「插圖 / 模型」切換
- [x] Node 內建測試執行器可以跑測試，不需要安裝任何套件；有測試斷言第 1 種主動輪轉 +θ 時，從動輪同向轉 θ·r主/r從
- [x] Three.js 經 CDN 以 ES module 載入並固定版本；第一次切到模型才載入，只看插圖時不會下載
- [x] 畫風：白底、黑色粗輪廓線、淡灰陰影；主動件用單一強調色
- [x] 切到模型時自動慢速播放
- [x] 模型模式下，點擊圖片區左右半邊和觸控滑動都不會翻頁；上下張按鈕與鍵盤左右鍵照常可用
- [x] 切回插圖後，現有的點擊與滑動翻頁行為完全不變
- [x] 整頁共用一個 3D 畫布；換卡片時釋放舊場景
- [x] 在本機靜態伺服器上可以看到第 1 種模型運轉
