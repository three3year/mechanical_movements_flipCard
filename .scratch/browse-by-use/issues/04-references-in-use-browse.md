# 04 — 用途瀏覽下的「第 N 種」、跳到圖號與返回

**What to build:** 在用途瀏覽下點說明裡的「第 N 種」時留在用途瀏覽:目標條目在目前用途大類裡有用途時,落在其中排最前的那個;否則落在它的第一個用途(依卡片上的用途順序);選中被指定的插圖,頁籤跟著換。「‹ 返回」/ Esc 回到原本的用途、原本的卡片與原本選中的插圖,可多層。「跳到圖號」在用途瀏覽下套用同一個落點規則,但清空返回堆疊。原書順序下的行為不變。見規格 `.scratch/browse-by-use/spec.md` 的「瀏覽模組」。

**Blocked by:** 03 — 用途瀏覽:兩排頁籤、跨用途翻頁、切換瀏覽方式

**Status:** ready-for-agent

- [ ] 返回回到原用途大類、原用途、原卡片(同一條目在兩個用途下時回到原本那一個)與原插圖,可多層依序退回;返回鍵文字照舊顯示來源條目
